## 1. BLUF / Executive Summary
UNC2452 (G0118) is a **revoked** ATT&CK intrusion set entry that was created to represent the actor cluster behind the **2020 SolarWinds supply-chain intrusion**. ATT&CK later **revoked UNC2452 and replaced it with [[30_CIPHER/03_Threat_Actors/G0016 - APT29|APT29]]**, reflecting updated attribution and consolidation of the activity under APT29.

Operationally, reporting associated with UNC2452 highlighted:
- **Software build pipeline compromise** (supply chain) enabling wide distribution of backdoored software.
- **Selective post-compromise actions** focused on stealth, credential/token abuse, and high-value collection (not broad disruption).
- **Cloud identity and federation abuse** (e.g., delegated permissions and token/certificate-related tradecraft) consistent with advanced espionage operations.

## 2. Attribution Notes
- **MITRE ATT&CK ID:** G0118 (UNC2452)
- **Status:** **Revoked by [[30_CIPHER/03_Threat_Actors/G0016 - APT29|APT29]]** (ATT&CK update notes).
- **Aliases used in public reporting:** Solorigate, StellarParticle, Dark Halo, SolarStorm (as referenced in ATT&CK/MITRE materials and common reporting).
- **Confidence:** Medium — ATT&CK originally described UNC2452 as **suspected Russian state-sponsored**; later activity is represented within APT29.

## 3. Motivations & Objectives
- **Motivation:** Espionage.
- **Objectives (observed/reported):**
  - Establish stealthy, durable access via trusted software distribution channels.
  - Abuse identity, delegated permissions, and authentication artifacts to sustain access.
  - Collect sensitive email and internal data from a subset of high-value targets.

## 4. Targeting Profile
- **Victim profile (as described in ATT&CK-era reporting):**
  - Government and high-value private sector organizations (consulting, technology, telecom, others).
  - Multi-region victim set spanning **North America, Europe, Asia, and the Middle East**.
  - At least one **think tank compromise** linked to activity observed by late 2019 (public reporting cited in ATT&CK-era materials).

## 5. Tradecraft Overview
Key behaviors and telemetry anchors associated with the UNC2452/SolarWinds reporting period:
- **Supply chain compromise** of a vendor build environment and software updates distributed through legitimate channels.
- **Payload staging and transfer** from attacker-controlled infrastructure into victim environments.
- **Cloud and identity abuse**, including manipulation of application/service principal credentials and delegated permissions in Microsoft 365/Entra ID contexts.
- **Email and data collection** with staging and exfiltration through web services.
- **Defense evasion** via obfuscation, masquerading, and artifact cleanup (including file deletion).
- **Scheduled task–based persistence/execution** and use of signed binaries/utilities for proxy execution patterns.

## 8. Infrastructure Patterns
Common infrastructure/ops patterns described in public reporting around the SolarWinds intrusion:
- Compromise of **vendor build systems** and downstream **trusted update mechanisms**.
- Use of **legitimate-looking infrastructure** and naming to blend with enterprise telemetry.
- Post-compromise activity often leveraging **cloud identity surfaces** (Entra ID/Azure AD, Microsoft 365) and **web-based endpoints** for control and data movement.

## 9. Campaign History
- **SolarWinds Compromise (C0024):** ATT&CK represents the SolarWinds supply chain operation as a campaign conducted by **APT29**. UNC2452 was an ATT&CK grouping used early in the public reporting period and later **revoked in favor of APT29**.  
  - https://attack.mitre.org/campaigns/C0024/

## 10. Known Indicators
ATT&CK does not provide a single durable IOC set for this cluster; treat IOCs as **time-bound and campaign-specific**. Prioritize behavior-based pivots:
- Orion-related build/update anomalies and unexpected DLL/module behavior in Orion processes.
- Suspicious creation/changes to **OAuth apps/service principals**, especially **credentials added** and unusual consent/permissions patterns.
- Exchange/Graph anomalies: unexpected mailbox access patterns, unusual delegate permission changes, atypical EWS/Graph usage.
- Identity artifacts: suspicious certificate/key access, token anomalies, federation trust changes.
- Scheduled task creation consistent with masquerading patterns; suspicious rundll32 usage; artifact deletion in proximity to access.

## 11. Defensive Recommendations
Detection engineering anchors (high-signal where properly scoped):
- **Identity/Cloud (Entra ID / M365):**
  - Alert on **service principal credential additions** and unusual application permission grants (esp. high privilege Graph scopes).
  - Monitor **Exchange delegate permission changes** and anomalous mailbox access (impossible travel, abnormal client apps, abnormal volume/targets).
  - Track federation configuration changes and suspicious certificate/key access patterns (where logged).
- **Endpoint:**
  - Enable and hunt **PowerShell Script Block Logging** and command-line telemetry for unusual automation tied to identity manipulation.
  - Monitor for **Scheduled Task** creation (T1053.005) with system-like naming, odd triggers, or suspicious binaries/paths.
  - Detect suspicious **rundll32** execution patterns, especially unusual DLL paths/exports.
  - Alert on bursts of **file deletion** and cleanup actions following credential/identity events.
- **Network:**
  - Proxy visibility for unusual outbound destinations and web-protocol C2-like patterns aligned with host/process context.
  - DLP/egress controls for exfil to web services from nonstandard hosts/users.
- **Supply chain hardening:**
  - Enforce secure build pipelines, signing key protections, reproducible builds where feasible, and continuous integrity verification for build outputs.
  - Validate vendor update artifacts (signing + behavior-based validation where possible).

## 12. Analyst Notes
- Treat UNC2452 as a **historical ATT&CK label**: the practical analytic value is as a bridge to older reports and tooling references (e.g., “UNC2452 layer”) while modern ATT&CK tracking for the SolarWinds campaign is under **APT29**.
- For modern detections, prioritize **identity control-plane telemetry** (app creds, delegated access, mailbox access patterns) alongside endpoint execution/persistence artifacts.
