# APT18

## 1. BLUF / Executive Summary
APT18 (MITRE ATT&CK **G0026**) is a China-attributed cyber espionage threat actor reported active since at least **2009**, with targeting spanning **technology**, **manufacturing**, **government**, **medical/healthcare**, and **human rights** organizations. Public reporting associated with the related label **Wekby** highlights phishing-led intrusions and malware families (notably [[30_CIPHER/05_Malware/HTTPBrowser]] / [[30_CIPHER/05_Malware/Pisloader]]) that can employ **DNS-based command-and-control** and obfuscation to sustain access and complicate analysis.

## 2. Attribution Notes
MITRE tracks the cluster as **APT18 (G0026)** with associated names including **TG-0416** and **Dynamite Panda**. Multiple public vendor reports use **Wekby** to describe activity that overlaps with APT18 naming in the same reporting ecosystems. Open-source attribution remains a probabilistic assessment; this note treats state linkage as **attributed** rather than legally adjudicated.

## 3. Motivations & Objectives
APT18 is consistently described as **espionage-driven**, seeking to collect sensitive data from strategically relevant sectors. Operational objectives described in public sources include establishing persistence, leveraging legitimate credentials/remote access where available, using web and DNS-based channels for C2 resilience, and applying obfuscation to reduce defender visibility.

## 4. Targeting Profile
- **Sectors (MITRE):** technology, manufacturing, human rights groups, government, medical/healthcare.
- **Additional sectors (vendor reporting):** aerospace/defense, telecommunications, construction/engineering, education.
- **Geography (reported):** U.S. victimology is repeatedly cited, with broader global targeting implied by sector breadth and cross-reporting.

## 5. Tradecraft Overview
Public reporting and MITRE technique associations characterize APT18 with:
- **Phishing-led access** themes (including IT/helpdesk-style lures described in vendor reporting).
- **C2 diversity** using both **HTTP/web protocols** and **DNS** channels for operational flexibility.
- **Persistence** via **Registry Run Keys / Startup Folder**.
- **Post-compromise activity** using Windows shell execution, basic discovery (system + file/directory), and tool transfer.
- **Obfuscation** (encoded/encrypted strings or payload content) to hinder analysis.
- **Operational housekeeping** such as deleting tools/batch files after use (reported in technique associations).

## 7. Malware & Tools Used
- [[30_CIPHER/05_Malware/HTTPBrowser]] — malware family referenced in multiple public sources and linked to web/DNS C2 patterns in Wekby/APT18 reporting.
- [[30_CIPHER/05_Malware/Pisloader]] — Unit 42-named family tied to Wekby reporting and DNS-based C2 behavior.
- [[30_CIPHER/05_Malware/gh0st RAT]] — MITRE-listed software associated with APT18.
- [[30_CIPHER/05_Malware/hcdLoader]] — MITRE-listed loader associated with APT18.
- [[30_CIPHER/05_Malware/cmd]] — Windows command shell usage noted in MITRE technique associations for APT18 activity.

## 8. Infrastructure Patterns
- [[Spearphishing]] with [[Helpdesk-themed lures]] (reported in vendor research).
- Use of both [[HTTP C2]] and [[DNS C2]] to provide redundancy and complicate network-based blocking.
- [[Domain churn]] / newly registered infrastructure appearing shortly before use (reported in vendor research), supporting short-lived staging and C2.

## 9. Campaign History
- **2009 (at least):** MITRE reports APT18 operating since at least this year.
- **2014-09-02:** CFR summarizes APT18 targeting human rights groups, government entities, and pharmaceutical/medical/industrial/IT sectors.
- **2015-07-06:** Vendor reporting under Wekby describes campaigns with IT-helpdesk style lures and DNS-based control channels in HTTPBrowser variants.
- **2015-07-13:** Mandiant/FireEye reporting notes APT18 quickly leveraging a newly leaked Flash zero-day (CVE-2015-5119) in phishing campaigns spanning multiple industries.
- **2016-05-24:** Unit 42 reports on Wekby activity using DNS requests for C2 and associates the observed malware with the HTTPBrowser ecosystem (naming the family Pisloader).

## 11. Defensive Recommendations
- Improve resilience against phishing-led access by emphasizing detection and response around user-driven execution and suspicious installer-like downloads associated with targeted lure themes.
- Monitor for combined **web + DNS** anomalous outbound patterns aligned to [[20_Entities/07_TTPs/T1071.001 - Application Layer Protocol: Web Protocols]] and [[20_Entities/07_TTPs/T1071.004 - Application Layer Protocol: DNS]] when correlated with new persistence artifacts.
- Alert on persistence creation aligned to [[20_Entities/07_TTPs/T1547.001 - Boot or Logon Autostart Execution: Registry Run Keys / Startup Folder]] and scheduled execution aligned to [[20_Entities/07_TTPs/T1053.002 - Scheduled Task/Job: At]] as correlation amplifiers after suspected initial access.
- Increase visibility into credential misuse patterns aligned to [[20_Entities/07_TTPs/T1078 - Valid Accounts]] (especially external remote service logins) and host discovery bursts aligned to [[20_Entities/07_TTPs/T1082 - System Information Discovery]] / [[20_Entities/07_TTPs/T1083 - File and Directory Discovery]].

## 12. Analyst Notes
- Public reporting frequently uses **Wekby** and **APT18** interchangeably in context; keep entity resolution conservative when merging datasets.
- APT18 tradecraft detail in public sources is often centered on **DNS-based C2**, **obfuscation**, and rapid exploit adoption in specific windows; avoid assuming all campaigns share identical tooling.
