# FIN10

## 1. BLUF / Executive Summary
FIN10 (**G0051**) is a financially motivated threat group reported active from at least **2013 through 2016**, primarily targeting **North American** organizations with a notable focus on **Canada**, including **casinos** and **mining**. Public reporting characterizes FIN10’s core model as **data-theft extortion**: compromise networks, steal sensitive business data (including customer PII), provide “proof” to victims via publicly accessible postings, and threaten broader disclosure and operational disruption if payment is not made.

## 2. Attribution Notes
- MITRE ATT&CK tracks FIN10 as **G0051** and describes the activity as financially motivated, focused on North America (2013–2016), and centered on extortion using stolen data.
- The key publicly cited foundation for FIN10 characterization is a 2017 FireEye iSIGHT Intelligence report describing a linked cluster of intrusions with near-parallel TTPs.
- Public reporting does not establish a reliable **country of origin**; “false-flag” posturing has been reported, so origin is left **blank**.

## 3. Motivations & Objectives
- **Motivation:** financial gain via extortion.
- **Objectives (reported):**
  - Steal sensitive corporate information to use as extortion leverage.
  - Increase pressure through threats of public exposure and, in some cases, disruptive/destructive actions.
  - Sustain access using common remote access and Windows-native techniques supported by publicly available tooling.

## 4. Targeting Profile
- **Regions:** North America, predominantly Canada (reported).
- **Sectors:** casinos/gaming and mining (reported).
- **Victim selection theme:** organizations likely to experience high business impact from data exposure and downtime, increasing extortion leverage.

## 5. Tradecraft Overview
- **Initial access (reported):** evidence from a subset of cases indicates spearphishing with malicious attachments and lures directing victims to actor-controlled content ([[20_Entities/07_TTPs/T1566.001 - Phishing: Spearphishing Attachment]], [[20_Entities/07_TTPs/T1204.001 - User Execution: Malicious Link]]). Reporting includes use of Windows HTML Application execution paths ([[20_Entities/07_TTPs/T1218.005 - System Binary Proxy Execution: Mshta]]).
- **Foothold & persistence:** heavy reliance on PowerShell and publicly available post-exploitation frameworks, including persistence via Registry Run Keys and Scheduled Tasks ([[20_Entities/07_TTPs/T1059.001 - Command and Scripting Interpreter: PowerShell]], [[20_Entities/07_TTPs/T1547.001 - Boot or Logon Autostart Execution: Registry Run Keys / Startup Folder]], [[20_Entities/07_TTPs/T1053.005 - Scheduled Task/Job: Scheduled Task]]).
- **Lateral movement & access:** use of RDP and stolen credentials/VPN access patterns, including movement via local administrator accounts ([[20_Entities/07_TTPs/T1021.001 - Remote Services: Remote Desktop Protocol]], [[20_Entities/07_TTPs/T1078 - Valid Accounts]], [[20_Entities/07_TTPs/T1078.003 - Valid Accounts: Local Accounts]]).
- **Recon & operations:** enumeration/discovery consistent with post-exploitation frameworks ([[20_Entities/07_TTPs/T1033 - System Owner/User Discovery]]) and tool movement inside environments ([[20_Entities/07_TTPs/T1570 - Lateral Tool Transfer]]).
- **Pressure tactics:** disruptive/destructive actions described as deletion of critical system files and shutdown/disruption mechanics ([[20_Entities/07_TTPs/T1070.004 - Indicator Removal: File Deletion]])—notably used as extortion “pressure,” not covert sabotage, in reported cases.

## 7. Malware & Tools Used
- Reported tooling (publicly available) used across FIN10 operations:
  - [[30_CIPHER/05_Malware/Metasploit]] / [[30_CIPHER/05_Malware/Meterpreter]] (foothold, post-exploitation functionality)
  - [[30_CIPHER/05_Malware/Empire]] (PowerShell-based post-exploitation; used for persistence mechanisms in reporting)
  - [[30_CIPHER/05_Malware/SplinterRAT]] (open-source remote access tooling observed in some cases)
- Public reporting emphasizes **limited or no use of bespoke malware**, instead leveraging widely available frameworks and scripts.

## 8. Infrastructure Patterns
- [[FIN10-controlled staging server]] used to host malicious artifacts linked from phishing lures (reported).
- [[Public proof-of-theft site]] used to demonstrate stolen data to victims and apply pressure (reported).
- [[Single-factor VPN access]] leveraging stolen credentials (reported).
- [[Internet-accessible RDP]] and RDP-based lateral movement patterns (reported).
- [[False-flag persona]] / narrative posturing reported in extortion communications (reported).

## 9. Campaign History
- **2013–2016:** Activity window described in MITRE and the primary vendor report; multiple intrusions in North America with strong Canada concentration.
- **2017-06-16:** Public publication of a detailed vendor report describing FIN10 as a linked set of cyber extortion intrusions; contemporaneous media coverage highlights casinos and mining as key victim sectors.

## 11. Defensive Recommendations
- Treat **data-theft extortion** as a primary risk: prioritize controls that reduce likelihood of bulk data access and accelerate detection of unusual staging/exfiltration behavior, especially from file servers and sensitive repositories.
- Strengthen defenses against spearphishing and lure-driven execution aligned to [[20_Entities/07_TTPs/T1566.001 - Phishing: Spearphishing Attachment]] and user execution patterns.
- Reduce exposure of remote access services: focus monitoring and hardening around RDP and VPN access patterns consistent with [[20_Entities/07_TTPs/T1021.001 - Remote Services: Remote Desktop Protocol]] and [[20_Entities/07_TTPs/T1078 - Valid Accounts]].
- Improve visibility for script-heavy and framework-driven behavior, particularly PowerShell and scheduled task persistence aligned to [[20_Entities/07_TTPs/T1059.001 - Command and Scripting Interpreter: PowerShell]] and [[20_Entities/07_TTPs/T1053.005 - Scheduled Task/Job: Scheduled Task]].
- Plan for “pressure” tactics: ensure resilience against disruptive actions described in reporting, including protection of critical system files, rapid containment, and recovery readiness.

## 12. Analyst Notes
- FIN10 is best understood as an early, well-documented example of **data-theft extortion** with explicit pressure mechanisms, not primarily as encryption-only ransomware.
- Public attribution does not credibly establish geographic origin; reported false-flag behavior further weakens origin inference.
- While the main activity window is described as 2013–2016, absence of public reporting after that period should not be treated as proof of cessation—only reduced visibility.
