# RTM

## 1. BLUF / Executive Summary
RTM (**G0048**), also known as “Read The Manual,” is a financially motivated cybercrime group assessed active since at least **2015** and primarily focused on victims connected to **remote banking systems (RBS)** in **Russia and neighboring countries**. The group is associated with a Delphi-based banking trojan tracked as [[30_CIPHER/05_Malware/RTM]] (with newer versions reported as [[30_CIPHER/05_Malware/Redaman]]). Public reporting describes targeted intrusion workflows that combine phishing, exploit-kit/malvertising delivery, and operator-driven post-compromise activity supported by legitimate remote access software and, in at least one reported campaign, ransomware ([[30_CIPHER/05_Malware/Quoter]]).

## 2. Attribution Notes
- RTM is tracked by MITRE ATT&CK as a **cybercriminal** activity cluster (not a state-sponsored APT label), with targeting centered on **remote banking systems** users in Russia and nearby countries.
- Public sources consistently attribute the activity to an organized criminal group and tooling ecosystem rather than a specific nation-state sponsor; therefore, **country of origin is left blank** while targeting geography is documented.

## 3. Motivations & Objectives
- **Motivation:** financial theft and monetization of access to business banking workflows.
- **Objectives (reported):** compromise endpoints used for RBS access, capture credentials/transaction context, enable fraudulent transfers, and maintain access long enough for operator-led theft; some activity has been reported to include ransomware as an additional monetization layer.

## 4. Targeting Profile
- **Primary victims:** businesses and users operating or interacting with **Remote Banking Systems (RBS)**.
- **Regions:** predominantly **Russia** and **neighboring countries**.
- **Sectors:** victim profiling commonly aligns to organizations that handle frequent bulk transfers (e.g., treasury/accounting functions), with vendor reporting noting activity affecting areas such as **transportation** and other commercial enterprises.

## 5. Tradecraft Overview
- **Initial access:** mixed delivery models including [[20_Entities/07_TTPs/T1566.001 - Phishing: Spearphishing Attachment]] / [[20_Entities/07_TTPs/T1204.002 - User Execution: Malicious File]], plus [[20_Entities/07_TTPs/T1189 - Drive-by Compromise]] routes tied to [[Exploit kit]] and [[Malvertising]] (including [[Yandex.Direct]]).
- **Persistence and remote operation:** persistence via [[20_Entities/07_TTPs/T1547.001 - Boot or Logon Autostart Execution: Registry Run Keys / Startup Folder]], with remote operator access supported by legitimate tooling (including modified remote desktop software) aligned to [[20_Entities/07_TTPs/T1219.002 - Remote Access Tools: Remote Desktop Software]].
- **C2 resilience:** use of a [[Dead drop resolver]] concept, reported as leveraging an [[LiveJournal RSS feed]] for resolving or updating encrypted infrastructure references ([[20_Entities/07_TTPs/T1102.001 - Web Service: Dead Drop Resolver]]).
- **Collection and theft enablement:** capabilities consistent with credential and context harvesting (e.g., [[20_Entities/07_TTPs/T1056.001 - Input Capture: Keylogging]], [[20_Entities/07_TTPs/T1113 - Screen Capture]], [[20_Entities/07_TTPs/T1115 - Clipboard Data]]) and automated acquisition of relevant artifacts ([[20_Entities/07_TTPs/T1119 - Automated Collection]]).
- **Operational security:** reported use of encryption and cleanup behaviors (e.g., [[20_Entities/07_TTPs/T1573.001 - Encrypted Channel: Symmetric Cryptography]]; [[20_Entities/07_TTPs/T1070.004 - Indicator Removal: File Deletion]]).

## 7. Malware & Tools Used
- [[30_CIPHER/05_Malware/RTM]] — Delphi-based custom banking trojan used by the RTM group; MITRE notes newer variants publicly reported as [[30_CIPHER/05_Malware/Redaman]].
- [[30_CIPHER/05_Malware/Redaman]] — name reported for newer versions/variants of RTM malware in public reporting and MITRE’s software entry.
- [[30_CIPHER/05_Malware/Quoter]] — ransomware identified in vendor reporting as used alongside RTM activity in at least one campaign.
- Legitimate remote access software used or modified in RTM-associated intrusions (reported):
  - [[30_CIPHER/05_Malware/TeamViewer]]
  - [[30_CIPHER/05_Malware/Remote Utilities]]
  - [[30_CIPHER/05_Malware/LiteManager]]
  - [[30_CIPHER/05_Malware/RMS]]

## 8. Infrastructure Patterns
- [[Spearphishing Attachment]] as a recurring delivery channel for targeted victim execution.
- [[Drive-by compromise]] through [[Exploit kit]] activity (including [[RIG Exploit Kit]] and [[Sundown Exploit Kit]]) and [[Malvertising]] via [[Yandex.Direct]] (reported).
- [[Dead drop resolver]] pattern using third-party content (reported as an [[LiveJournal RSS feed]]) to distribute or refresh encrypted infrastructure references.
- Use of legitimate remote desktop/control tooling (including modified instances) as an operational enabler for hands-on activity.

## 9. Campaign History
- **2015+ (MITRE/ESET):** RTM activity tracked as active since at least 2015, with a focus on RBS users in Russia and neighboring countries.
- **2017-02:** ESET publishes a detailed white paper describing the RTM banking trojan and operational patterns (Read The Manual).
- **2021-03:** Kaspersky reports a campaign combining RTM banking trojan activity with a new ransomware component dubbed [[30_CIPHER/05_Malware/Quoter]], alongside legitimate remote access tooling.

## 11. Defensive Recommendations
- Prioritize controls and detection for targeted phishing leading to user execution aligned to [[20_Entities/07_TTPs/T1566.001 - Phishing: Spearphishing Attachment]] and [[20_Entities/07_TTPs/T1204.002 - User Execution: Malicious File]].
- Monitor for anomalous use of remote desktop/admin tooling and “legitimate tool misuse” aligned to [[20_Entities/07_TTPs/T1219.002 - Remote Access Tools: Remote Desktop Software]], especially where registry autoruns or persistence behaviors are present ([[20_Entities/07_TTPs/T1547.001 - Boot or Logon Autostart Execution: Registry Run Keys / Startup Folder]]).
- Focus on behavioral detections for banking-trojan collection functions (e.g., [[20_Entities/07_TTPs/T1056.001 - Input Capture: Keylogging]], [[20_Entities/07_TTPs/T1113 - Screen Capture]], [[20_Entities/07_TTPs/T1115 - Clipboard Data]]) in systems used for treasury and bulk transfers.
- Treat third-party web content used as resolver infrastructure (dead-drop patterns) as a key investigative lead, aligned to [[20_Entities/07_TTPs/T1102.001 - Web Service: Dead Drop Resolver]].
- Maintain ransomware readiness given reported multi-tool campaigns that can include ransomware components (e.g., [[30_CIPHER/05_Malware/Quoter]]), emphasizing rapid containment and recovery planning.

## 12. Analyst Notes
- RTM’s public reporting includes both malware and actor naming overlap (“RTM” for the group and the trojan). This note anchors identity to **MITRE G0048** and treats [[30_CIPHER/05_Malware/RTM]] as the primary associated malware family.
- Origin attribution is not consistently or authoritatively established in the cited sources; avoid converting targeting geography into origin claims.
