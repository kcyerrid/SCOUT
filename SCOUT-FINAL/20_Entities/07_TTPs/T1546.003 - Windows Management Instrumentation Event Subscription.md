# T1546.003 – Windows Management Instrumentation Event Subscription

## 1. Technique Overview
**Windows Management Instrumentation (WMI) Event Subscription (T1546.003)** is a sub-technique of **Event Triggered Execution (T1546)** in **MITRE ATT&CK v18**. Adversaries abuse **permanent WMI event subscriptions** to register malicious actions that execute automatically when specified system events occur, such as system startup, user logon, or process creation.

Because WMI subscriptions are stored in the WMI repository and execute without user interaction, this technique provides stealthy, fileless persistence that is difficult to detect.

## 2. Adversary Objectives
Adversaries use WMI event subscriptions to:
- Maintain persistence without traditional startup artifacts
- Execute payloads conditionally based on system events
- Evade detection through fileless execution
- Regain execution after system reboots

## 3. Common Abuse Patterns
- Creating permanent WMI event subscriptions using:
  - `CommandLineEventConsumer`
  - `ActiveScriptEventConsumer`
- Binding event filters to consumers via `FilterToConsumerBinding`
- Triggering execution on events such as logon, uptime thresholds, or process creation
- Executing PowerShell, VBScript, or binaries via WMI consumers
- Using WMI namespaces that are rarely inspected by defenders

## 4. Detection Considerations
Detection relies on **WMI repository inspection and behavioral monitoring**, including:
- Enumerating permanent WMI event subscriptions
- Monitoring creation of WMI event filters and consumers
- Detecting suspicious command execution via WMI
- Correlating WMI-triggered execution with anomalous processes
- Auditing WMI namespaces for unauthorized changes

## 5. Defensive Mitigations
- Restrict permissions required to create WMI event subscriptions
- Monitor and alert on WMI permanent subscription creation
- Regularly audit WMI event filters, consumers, and bindings
- Use endpoint security tools with WMI visibility
- Remove unauthorized WMI subscriptions during incident response

## 6. Operational Impact
If successful, T1546.003 can:
- Provide durable, fileless persistence
- Execute code with elevated privileges depending on context
- Evade detection focused on files or registry artifacts
- Complicate remediation due to hidden configuration storage

## 7. Analyst Notes
WMI event subscriptions are a favored persistence mechanism among sophisticated attackers because they are **stealthy, resilient, and flexible**. During investigations, analysts should explicitly enumerate **all permanent WMI subscriptions**, as they often persist unnoticed even after malware binaries are removed.
