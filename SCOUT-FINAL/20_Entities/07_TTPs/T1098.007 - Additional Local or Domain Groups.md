# T1098.007 – Additional Local or Domain Groups

## 1. Technique Overview
**Additional Local or Domain Groups (T1098.007)** is a sub-technique of **Account Manipulation (T1098)** in MITRE ATT&CK v18. It describes adversary activity in which **existing accounts are added to privileged local or domain groups** to gain elevated access or ensure persistence. This approach avoids the creation of new accounts and leverages trusted administrative constructs.

This technique is commonly observed in Windows and Active Directory environments following credential compromise or initial privilege escalation.

## 2. Adversary Objectives
Adversaries use this technique to:
- Escalate privileges to administrative levels
- Maintain persistence through trusted group memberships
- Enable lateral movement across systems
- Blend malicious access into legitimate administrative activity

## 3. Common Abuse Patterns
- Adding users to **Domain Admins**, **Enterprise Admins**, or **Schema Admins**
- Adding accounts to local **Administrators** groups on endpoints or servers
- Modifying membership of service or backup operator groups
- Using group policy or administrative tools to propagate group membership
- Adding compromised service accounts to privileged groups

## 4. Detection Considerations
Detection depends on **identity and directory service monitoring**, including:
- Alerts on changes to privileged group memberships
- Monitoring Active Directory event logs (e.g., group membership changes)
- Detecting privilege changes outside approved change windows
- Correlating group modifications with anomalous authentication activity
- Reviewing local group changes across endpoints

## 5. Defensive Mitigations
- Enforce least privilege and minimize membership in privileged groups
- Require approval workflows for group membership changes
- Enable logging and alerting for directory and local group modifications
- Implement just-in-time (JIT) administration for privileged access
- Regularly audit group memberships and remove unnecessary accounts

## 6. Operational Impact
If successful, T1098.007 can:
- Provide attackers with broad administrative control
- Enable rapid lateral movement and follow-on attacks
- Undermine trust in identity and access controls
- Complicate incident response if group changes are overlooked

## 7. Analyst Notes
Group membership abuse is one of the most reliable and durable persistence mechanisms in enterprise environments. During incident response, defenders must validate **current and historical group membership changes**, as attackers may add accounts temporarily and remove them to evade detection.
