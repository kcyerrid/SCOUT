# T1547.014 – Active Setup

## 1. Technique Overview
**Active Setup (T1547.014)** is a sub-technique of **Boot or Logon Autostart Execution (T1547)** in MITRE ATT&CK v18. Adversaries abuse the Windows **Active Setup** mechanism to execute malicious code **once per user** when a user logs on. Active Setup is intended to run initialization tasks for applications on a per-user basis, making it an effective persistence mechanism that targets new or existing user profiles.

Because Active Setup executes under user context at logon and is commonly used by legitimate software, malicious abuse can blend into normal system behavior.

## 2. Adversary Objectives
Adversaries use this technique to:
- Achieve per-user persistence without relying on Run keys
- Execute payloads for newly created or existing user accounts
- Bypass some autorun and startup detections
- Maintain access across multiple user sessions

## 3. Common Abuse Patterns
- Creating or modifying Active Setup registry entries under:
  - `HKLM\Software\Microsoft\Active Setup\Installed Components`
- Setting the `StubPath` value to execute attacker-controlled binaries or scripts
- Masquerading malicious components as legitimate application installers
- Using Active Setup to target multiple users on shared systems
- Combining Active Setup with other persistence mechanisms for redundancy

## 4. Detection Considerations
Detection relies on **registry and logon activity monitoring**, including:
- Monitoring creation or modification of Active Setup registry keys
- Detecting suspicious or unexpected `StubPath` commands
- Correlating Active Setup execution with user logon events
- Reviewing per-user registry entries under `HKCU`
- Comparing Active Setup components against known software inventories

## 5. Defensive Mitigations
- Monitor and audit Active Setup registry locations
- Restrict administrative access to Active Setup configuration
- Use application allowlisting to prevent execution of unauthorized binaries
- Enable registry integrity monitoring
- Review Active Setup entries during incident response and system audits

## 6. Operational Impact
If successful, T1547.014 can:
- Provide durable, user-specific persistence
- Enable execution without traditional startup artifacts
- Affect multiple users on the same system
- Complicate remediation if not all user profiles are reviewed

## 7. Analyst Notes
Active Setup persistence is frequently overlooked during investigations because it does not behave like typical autorun mechanisms. Analysts should explicitly review **both system-wide and per-user Active Setup entries**, especially on shared workstations or servers where multiple users log in.
