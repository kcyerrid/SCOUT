# T1037.004 – RC Scripts

## 1. Technique Overview
**RC Scripts (T1037.004)** is a sub-technique of **Boot or Logon Initialization Scripts (T1037)** in **MITRE ATT&CK v18**. Adversaries abuse **run-command (rc) scripts**, which are executed during system initialization on Linux and Unix-like operating systems, to achieve persistent execution of malicious code at boot time.

RC scripts are commonly used for legitimate service startup and configuration, making them a powerful persistence mechanism when modified or replaced by attackers.

## 2. Adversary Objectives
Adversaries use rc scripts to:
- Maintain persistence across system reboots
- Execute malicious payloads early in the boot process
- Run code with elevated or root privileges
- Blend malicious logic into trusted system initialization routines

## 3. Common Abuse Patterns
- Modifying scripts in locations such as:
  - `/etc/rc.local`
  - `/etc/init.d/`
  - `/etc/rc*.d/`
- Adding malicious commands to existing startup scripts
- Creating new rc scripts and registering them for execution
- Masquerading malicious scripts as legitimate services
- Leveraging init systems (e.g., SysVinit) to ensure execution order

## 4. Detection Considerations
Detection relies on **file integrity and startup monitoring**, including:
- Monitoring changes to rc script directories and files
- Detecting unauthorized creation of new init scripts
- Comparing startup scripts against known-good baselines
- Correlating boot events with unexpected process execution
- Reviewing service startup logs for anomalies

## 5. Defensive Mitigations
- Restrict write permissions to system initialization directories
- Implement file integrity monitoring for rc scripts
- Audit startup scripts regularly for unauthorized changes
- Use configuration management tools to enforce known-good states
- Review boot-time services during incident response

## 6. Operational Impact
If successful, T1037.004 can:
- Provide durable, system-level persistence
- Enable execution with elevated privileges
- Survive reboots and service restarts
- Complicate remediation if scripts are not fully audited

## 7. Analyst Notes
RC script abuse is common in environments using legacy init systems or minimal security controls. Even in modern Linux distributions that favor `systemd`, legacy rc scripts may still be honored for compatibility. Analysts should verify **all boot-time execution paths**, not just the primary init framework.
