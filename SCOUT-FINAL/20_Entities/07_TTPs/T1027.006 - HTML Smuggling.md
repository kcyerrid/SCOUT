# Obfuscated Files or Information: HTML Smuggling (T1027.006)

## 1. Summary
HTML Smuggling describes adversaries **delivering malicious payloads to a target system by embedding them within HTML or browser-executed scripts**, rather than transmitting the payload directly over the network. The malicious file is reconstructed locally within the victim’s browser, bypassing network-based inspection and content filtering.

Adversaries use this technique to:
- Evade network and proxy-based malware detection
- Bypass email and web gateway content scanning
- Deliver payloads without direct file transfer
- Abuse trusted browser execution contexts

---

## 2. Technical Overview
In HTML smuggling, the payload is encoded or fragmented within HTML, JavaScript, or related web content. When a user opens the HTML file or visits a malicious webpage, client-side scripts:

- Decode or reconstruct the payload in memory
- Create a file locally using browser APIs
- Prompt the user to save or automatically write the file
- Initiate execution via user interaction or follow-on steps

Common techniques include:
- Base64-encoded payloads embedded in JavaScript
- Blob and File API usage to generate files
- Use of HTML attachments delivered via phishing
- Dynamic reconstruction of executable or archive files

Indicators include:
- HTML or JavaScript files creating binary blobs
- File creation events initiated by browser processes
- Downloads that do not traverse traditional network file inspection paths
- User interaction followed closely by suspicious file execution

---

## 3. Subtechnique Considerations
Key considerations for T1027.006:
- Commonly paired with **Phishing (T1566)** for delivery
- Highly effective against perimeter defenses
- Relies on browser trust and user interaction
- Payload inspection shifts from network to endpoint

HTML smuggling **exploits gaps between network visibility and endpoint behavior**.

---

## 4. Procedure Examples
Representative adversary behaviors include:
- Sending HTML attachments that reconstruct malware locally
- Hosting malicious HTML pages that generate executables
- Using JavaScript to assemble payloads from encoded fragments
- Triggering file downloads without direct binary transfer

*(Examples are representative and intentionally non-operational.)*

---

## 5. Detection Guidance
Detection should emphasize **browser and endpoint telemetry**:
- Monitor browsers creating executable or archive files
- Detect use of Blob, File, or download APIs for binary creation
- Correlate email or web delivery with local file creation
- Identify suspicious timing between file creation and execution

### Data Source Notes
- **Browser telemetry**: Identify file creation behaviors
- **EDR telemetry**: Detect execution chains originating from browsers
- **Email gateway logs**: Identify HTML attachment delivery

Common false positives:
- Legitimate web applications using client-side file generation
- SaaS platforms generating user-requested files

Tuning guidance:
- Baseline expected browser file-generation workflows
- Elevate alerts when browser-generated files are executable

---

## 6. Response Guidance
When suspected:
1. Isolate affected endpoint if execution occurs
2. Collect HTML and script artifacts
3. Reconstruct and analyze generated payloads
4. Identify delivery channels and user interactions
5. Block associated URLs, senders, or HTML patterns

## 8. SOC Relevance
T1027.006 is critical because:
- Network security controls may never see the payload
- Browser activity becomes the primary attack vector
- Detection requires endpoint and user-context awareness

SOC teams must treat **browser-driven file creation as a high-risk signal**.

---

## 9. Threat Actor Usage
Commonly used by:

- Ransomware affiliates

## 10. Campaign Usage
Observed in:

## 11. Malware Usage
Associated with:
- Loaders and droppers
- Ransomware payload delivery
- Credential-stealing malware

---

## 12. Mitigations
Recommended mitigations:
- Block or restrict HTML attachments
- Disable unnecessary browser scripting features
- Monitor and restrict browser-generated executables
- Educate users on suspicious HTML files

---

## 13. Testing & Validation
Validation approaches:
- Deliver benign HTML smuggling samples in lab
- Validate alerts on browser-based file creation
- Test SOC response to HTML-based delivery
- Ensure tooling captures browser-to-file execution chains
