# Spearphishing Attachment (T1566.001)

## 1. Summary
Spearphishing Attachment describes adversary delivery of malicious files via targeted phishing emails. These attachments are designed to entice users into opening them, resulting in code execution, malware delivery, or credential harvesting. This subtechnique remains one of the most reliable initial access vectors due to its effectiveness against human targets.

Attachments are often tailored to the victim’s role, industry, or current events to increase credibility and success rates.

---

## 2. Technical Overview
Adversaries send emails containing malicious attachments that rely on user interaction to trigger execution.

Common attachment formats include:
- Microsoft Office documents with embedded macros
- PDF files containing malicious scripts or links
- Archive files (ZIP, ISO, RAR) containing executable content
- HTML or IMG files used for credential harvesting or smuggling

Execution mechanisms may involve macro execution, script invocation, or user-enabled execution of embedded payloads.

Artifacts include email delivery metadata, file creation events, macro execution logs, and child process creation from user applications.

---

## 3. Subtechnique Considerations
T1566.001 is differentiated from other phishing subtechniques by its reliance on **file-based payload delivery**.

Key considerations include:
- Effectiveness depends heavily on user interaction
- Macro restrictions and file type blocking significantly reduce success
- Archive-based delivery can evade basic filtering controls

---

## 4. Procedure Examples
Observed adversary procedures include:
- Sending invoices or shipping documents as macro-enabled Office files
- Delivering password-protected archives to evade scanning
- Using HTML smuggling to reconstruct payloads client-side
- Embedding malicious scripts that launch secondary payloads

Analysts may observe file execution shortly after email delivery and user interaction.

---

## 5. Detection Guidance
Detection should focus on attachment handling and execution:
- Emails with uncommon or risky attachment types
- Attachments spawning child processes (e.g., Office → PowerShell)
- Macro execution events on endpoints
- File writes to temporary or user directories followed by execution

Correlation between email, file, and process telemetry is critical.

### Data Source Notes
- **Email Gateway Logs:** Primary source for initial detection
- **Endpoint Logs:** Required to confirm successful execution
- **Process Execution:** High-signal when Office or PDF readers spawn scripts

---

## 6. Response Guidance
When spearphishing attachments are identified:
- Remove malicious emails from all mailboxes
- Reset credentials for affected users
- Isolate endpoints if execution occurred
- Search for secondary payloads or persistence

Preserve email samples and endpoint artifacts for analysis.

## 8. SOC Relevance
Spearphishing attachments are a leading cause of initial compromise and ransomware deployment. SOC effectiveness depends on tight integration between email security, endpoint telemetry, and rapid user reporting.

---

## 9. Threat Actor Usage
This subtechnique is widely used by:
- Ransomware affiliates
- Financially motivated cybercriminals
- Advanced persistent threat groups conducting targeted intrusions

Confidence in widespread usage is extremely high.

---

## 10. Campaign Usage
Spearphishing attachments appear in:
- Targeted ransomware intrusion campaigns
- Credential harvesting operations
- Malware loader distribution waves

## 12. Mitigations
Effective mitigations include:
- Blocking or restricting macro-enabled documents
- Attachment sandboxing and detonation
- Enforcing MFA to reduce credential theft impact
- User awareness training focused on attachments
- Blocking risky attachment types at the gateway

---

## 13. Testing & Validation
Validation approaches include:
- Phishing simulations with attachment payloads
- Purple team exercises measuring execution detection
- Review of Office macro and child process alerts

Successful validation results in early detection or prevention.
