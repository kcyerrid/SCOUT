## 1. Summary
Adversaries may acquire credentials from **macOS Keychain**, the native credential management system storing passwords, private keys, certificates, and sensitive application data. Access can occur via UI tools, command-line utilities, or direct file access to Keychain databases.

## 2. Technical Overview
Keychain access patterns relevant to defenders:
- **Command-line access via `security`:** Used to query or dump Keychain content (notable when executed by non-admin tools or suspicious parent processes).
- **Keychain file access:** Reads of `~/Library/Keychains/` and system Keychain locations may indicate harvesting or staging.
- **API-based queries:** Calls into Keychain Services APIs (where telemetry exists) may indicate programmatic collection.
- **Prompt/interaction artifacts:** Some access requires Keychain unlock/password prompts; adversaries may rely on already-unlocked sessions or user context.

## 3. Subtechnique Considerations
This subtechnique is macOS-specific:
- Emphasize **process lineage + file access correlation** (unknown binary + Keychain DB access).
- Use additional subtechniques for other platforms/stores (e.g., Windows Credential Manager, browser credential DBs).

## 4. Procedure Examples
Observed implementations include:
- Dumping Keychain data via `security` utility and staging results for exfiltration.
- Copying Keychain files from user directories for offline processing.
- Querying Keychain entries via Keychain Services APIs to collect specific secrets.

## 5. Detection Guidance
High-signal detections:
- **Process creation:** `security` executed with arguments suggesting enumeration/dump activity; flag unusual parent processes (Office, browsers, downloaders).
- **File access:** Non-Apple or unsigned processes reading Keychain directories:
  - `~/Library/Keychains/`
  - `/Library/Keychains/`
  - `/Network/Library/Keychains/`
- **Privilege/context anomalies:** Keychain access by background daemons or tools without a user-interactive need.
- **Post-collection behavior:** Immediate archive creation, credential reuse attempts, or outbound connections following Keychain access.

Triage pivots:
- Identify the accessing process (hash, signature, notarization status).
- Determine whether Keychain was unlocked at time of access (user session state).
- Check for subsequent authentication attempts using harvested credentials.

### Data Source Notes
- Endpoint: process creation + full command line, file access telemetry for Keychain paths, code-signing/notarization metadata, and (if available) Keychain API/audit telemetry.
- Network: outbound connections shortly after Keychain access; data staging indicators (archives).

## 6. Response Guidance
1. **Contain:** Isolate host if active dumping is detected; terminate offending process where safe.
2. **Credential reset:** Assume compromise for credentials stored in Keychain; prioritize admin, VPN, email, and cloud access tokens.
3. **Hunt:** Search fleet for `security` invocations and Keychain directory access by non-standard processes.
4. **Hardening:** Reduce credential storage where feasible; enforce MFA and reduce local secret persistence.

## 8. SOC Relevance
- **Severity:** High (Keychain often contains VPN, browser, email, and certificate material).
- **Best signals:** Unusual `security` usage; unknown process reading Keychain DBs.
- **False positives:** Legitimate password manager integrations, IT scripts, EDR inspections—control with allowlists and admin device scoping.

## 12. Mitigations
- **Password Policies (M1027):** Consider separating Keychain password from login password to add friction.
- **Principle of least privilege:** Limit tools/users with access to Keychain data; reduce admin use on endpoints.
- **MFA everywhere:** Reduce impact of credential theft from local stores.

## 13. Testing & Validation
- Validate detections in a controlled macOS lab by:
  - Alerting on suspicious `security` execution and Keychain directory reads.
  - Correlating process execution with file access and outbound connections.
- Confirm that allowlists cover sanctioned IT workflows without suppressing novel binaries.
