# Hide Artifacts: VBA Stomping (T1564.007)

## 1. Summary
VBA Stomping is a defense evasion technique in which adversaries **remove or alter the human-readable VBA macro source code in Microsoft Office documents while leaving compiled macro bytecode intact**. This allows malicious macros to execute as intended while appearing benign or empty during static analysis and manual inspection.

This technique is commonly used to:
- Evade static analysis and sandbox inspection
- Bypass macro security reviews
- Conceal malicious logic from analysts
- Increase the effectiveness of phishing-based delivery

---

## 2. Technical Overview
Microsoft Office documents containing macros store:
- **Readable VBA source code**, and
- **Compiled p-code (bytecode)** used during execution

In VBA stomping, adversaries:
- Delete or overwrite the readable source code
- Preserve or modify the compiled p-code
- Ensure execution still occurs when the document is opened

As a result:
- Analysts inspecting macros see empty or benign code
- Macro execution still performs malicious actions
- Static scanners relying on source inspection may fail

Artifacts and indicators include:
- Discrepancies between VBA source and compiled code
- Macro-enabled documents with minimal or empty source
- Execution behavior inconsistent with visible macro content

---

## 3. Subtechnique Considerations
Key considerations for T1564.007:
- Effective against analysts relying on manual review
- Requires tooling capable of manipulating Office internals
- Often combined with obfuscation (T1027)
- Detection requires macro execution or deep inspection

This technique reflects **moderate to high attacker sophistication**.

---

## 4. Procedure Examples
Representative adversary behaviors include:
- Delivering macro-enabled documents via phishing
- Removing visible VBA code after compiling malicious logic
- Using stomping tools to preserve execution functionality
- Triggering macro execution on document open

*(Examples are representative and intentionally non-operational.)*

---

## 5. Detection Guidance
Detection requires **behavioral and structural analysis**:
- Compare VBA source code with compiled macro behavior
- Flag macro-enabled documents with empty or minimal source
- Monitor Office spawning child processes unexpectedly
- Correlate macro execution with network or filesystem activity

### Data Source Notes
- **Office telemetry**: Macro execution and security events
- **Process telemetry**: Office child processes
- **File inspection tools**: Required to detect source/p-code mismatch

Common false positives:
- Corrupted Office documents
- Poorly authored legitimate macros (rare)

Tuning guidance:
- Elevate severity when macro execution follows document open
- Prioritize documents with macros but no visible logic

---

## 6. Response Guidance
When suspected:
1. Detonate document in a controlled environment
2. Extract and analyze compiled macro code
3. Review child process and network activity
4. Quarantine related emails and documents
5. Hunt for similar artifacts across the environment

## 9. Threat Actor Usage
This technique has been used by:
- Financially motivated crimeware groups
- Malware distributors leveraging phishing
- Actors targeting enterprises reliant on Office tooling

---

## 10. Campaign Usage
Observed in:
- Macro-based phishing campaigns
- Loader delivery operations
- Initial access stages of ransomware intrusions

---

## 11. Malware Usage
Frequently associated with:
- Macro-based droppers
- Loader frameworks
- Banking trojans and ransomware loaders

---

## 12. Mitigations
Recommended mitigations:
- Disable macros by default
- Use Office Attack Surface Reduction rules
- Enforce protected view for downloaded documents
- Educate users on phishing risks
- Deploy sandboxing capable of macro execution analysis

---

## 13. Testing & Validation
Validation approaches:
- Create benign macro documents and test stomping detection
- Validate alerts on Office child process creation
- Test macro execution telemetry in SIEM/EDR
- Review SOC playbooks for document-based threats
