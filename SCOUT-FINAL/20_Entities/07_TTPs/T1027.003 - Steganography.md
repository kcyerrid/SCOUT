# Obfuscated Files or Information: Steganography (T1027.003)

## 1. Summary
Steganography describes adversaries **concealing malicious code, configuration data, or commands within seemingly benign files** such as images, audio, video, or documents. Unlike encryption or packing, steganography hides the *existence* of malicious content rather than merely obscuring its meaning.

Adversaries use this technique to:
- Evade content inspection and malware scanning
- Bypass email, web, and proxy security controls
- Covertly deliver payloads or commands
- Blend malicious content into normal user workflows

---

## 2. Technical Overview
Steganography embeds hidden data within carrier files by manipulating elements that are typically ignored during normal use. Adversaries leverage techniques such as:

- Least Significant Bit (LSB) manipulation in images or audio
- Embedding payloads in metadata or unused file sections
- Appending hidden data beyond logical end-of-file
- Encoding commands within pixel patterns or color channels
- Using custom decoding routines at runtime

Common carrier formats:
- Images (PNG, JPG, BMP)
- Audio files (WAV, MP3)
- Video files
- PDF and Office documents
- Web-delivered media content

Indicators include:
- Media files with abnormal entropy patterns
- Files significantly larger than visually expected
- Network transfers of media files followed by execution
- Media files accessed by non-media processes

---

## 3. Subtechnique Considerations
Key considerations for T1027.003:
- Often combined with **Application Layer Protocols (T1071)** for delivery
- Common in phishing and web-based payload delivery
- Detection is challenging without deep content inspection
- Decoding typically occurs in memory at runtime

Steganography is particularly effective against **content-based security controls**.

---

## 4. Procedure Examples
Representative adversary behaviors include:
- Delivering images via phishing emails containing hidden payloads
- Downloading media files that decode commands at runtime
- Using social media or image hosting sites as payload repositories
- Embedding configuration data within benign-looking files

*(Examples are representative and intentionally non-operational.)*

---

## 5. Detection Guidance
Detection should emphasize **contextual and behavioral analysis**:
- Identify media files accessed by scripting engines or executables
- Monitor execution following media file access
- Detect abnormal entropy or structural anomalies in media files
- Correlate network downloads of media with suspicious process activity

### Data Source Notes
- **Email gateway logs**: Identify suspicious attachments
- **Network traffic logs**: Detect media delivery patterns
- **EDR telemetry**: Identify decoding behavior

Common false positives:
- Legitimate steganography tools
- Media-heavy workflows (design, marketing)

Tuning guidance:
- Focus on execution context rather than file type alone
- Elevate alerts when media files precede code execution

---

## 6. Response Guidance
When suspected:
1. Capture and preserve carrier files for analysis
2. Extract hidden data using forensic tools
3. Identify decoding logic and execution flow
4. Hunt for similar carrier files across the environment
5. Block delivery channels used for steganographic payloads

## 8. SOC Relevance
T1027.003 is relevant because:
- Malicious content may appear completely benign
- Traditional file-type filtering is ineffective
- Attacks may blend into normal user activity

SOC teams must evaluate **file usage context**, not just file type.

---

## 9. Threat Actor Usage
Commonly used by:
- Advanced persistent threats
- Stealth-focused malware operators
- Actors leveraging public content platforms

---

## 10. Campaign Usage
Observed in:
- Phishing-based initial access campaigns
- Web-based command-and-control operations
- Long-dwell, low-noise intrusions

---

## 11. Malware Usage
Associated with:
- Loaders and droppers
- Covert C2 frameworks
- Fileless and memory-resident malware

---

## 12. Mitigations
Recommended mitigations:
- Restrict execution from user-writable directories
- Inspect media file handling by non-media processes
- Apply sandboxing to suspicious downloads
- Monitor outbound connections following media access

---

## 13. Testing & Validation
Validation approaches:
- Deliver benign steganographic samples in test environments
- Validate alerts on decode-and-execute behavior
- Test SOC playbooks for covert payload delivery
- Ensure tooling supports media analysis
