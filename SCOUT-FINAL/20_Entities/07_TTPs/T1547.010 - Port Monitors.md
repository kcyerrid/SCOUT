# T1547.010 – Port Monitors

## 1. Technique Overview
**Port Monitors (T1547.010)** is a sub-technique of **Boot or Logon Autostart Execution (T1547)** in MITRE ATT&CK v18. Adversaries abuse Windows **print port monitors**, which are implemented as DLLs loaded by the **Print Spooler service (`spoolsv.exe`)**, to achieve persistent execution. By registering a malicious port monitor, attacker-controlled code is executed whenever the spooler service starts, typically at system boot.

Because the Print Spooler runs with elevated privileges, this technique can provide both **persistence and privilege escalation**.

## 2. Adversary Objectives
Adversaries use this technique to:
- Achieve reliable execution at system startup
- Run code in a privileged service context
- Blend persistence into legitimate print subsystem activity
- Support follow-on actions such as credential access or lateral movement

## 3. Common Abuse Patterns
- Registering a malicious port monitor DLL via:
  - `HKLM\SYSTEM\CurrentControlSet\Control\Print\Monitors`
- Masquerading malicious DLLs as legitimate printer components
- Leveraging Print Spooler restart events to trigger execution
- Combining port monitor persistence with other spooler abuses
- Using this technique on systems where the Print Spooler is enabled by default

## 4. Detection Considerations
Detection requires **service, registry, and DLL load monitoring**, including:
- Monitoring changes to Print Monitor registry keys
- Detecting new or unsigned DLLs loaded by `spoolsv.exe`
- Alerting on port monitor additions outside approved printer installations
- Correlating spooler restarts with suspicious DLL loads
- Reviewing print subsystem configuration during incident response

## 5. Defensive Mitigations
- Disable the Print Spooler service on systems where it is not required
- Restrict administrative privileges needed to modify printer configurations
- Monitor integrity of print-related registry keys and DLLs
- Enforce code signing and allowlisting for system services
- Treat unauthorized port monitor changes as high-severity incidents

## 6. Operational Impact
If successful, T1547.010 can:
- Provide durable, high-privilege persistence
- Enable execution during every spooler service start
- Facilitate stealthy malware operation
- Complicate detection due to legitimate use of the print subsystem

## 7. Analyst Notes
Port monitor abuse is uncommon but extremely dangerous due to its **privileged execution context** and low visibility. Many organizations overlook print subsystem monitoring entirely. During response, analysts should explicitly inspect Print Spooler configuration and registered monitors, especially when no obvious persistence mechanisms are found.
