# Domain Policy Modification: Domain Trust Modification (T1484.002)

## 1. Summary
This subtechnique describes adversaries **modifying or abusing Active Directory trust relationships** between domains or forests. Domain trusts define how authentication and authorization flow across boundaries; altering them can grant attackers **expanded access, lateral movement paths, or persistent cross-domain privileges**.

T1484.002 is commonly used to:
- Expand access beyond the initially compromised domain
- Enable stealthy lateral movement across trusts
- Maintain long-term access across forest boundaries
- Undermine security assumptions in multi-domain environments

---

## 2. Technical Overview
Active Directory trusts govern authentication between domains and forests. Adversaries abuse these mechanisms by:
- Creating new trusts between domains
- Modifying trust direction (one-way vs. two-way)
- Weakening trust security settings
- Exploiting transitive trust relationships

Common artifacts include:
- Changes to trust objects in Active Directory
- Authentication events crossing unexpected domain boundaries
- Elevated access in trusted domains without direct compromise
- Increased inter-domain authentication traffic

---

## 3. Subtechnique Considerations
Key considerations for T1484.002:
- Requires high-privilege access (Domain Admin or equivalent)
- Particularly dangerous in multi-domain or forest environments
- Trust changes can persist indefinitely
- Often overlooked due to infrequent legitimate changes

Trust abuse dramatically increases attacker blast radius.

---

## 4. Procedure Examples
Observed adversary procedures include:
- Creating bidirectional trusts to enable unrestricted access
- Modifying trust attributes to weaken authentication controls
- Leveraging existing trusts to pivot into sensitive domains
- Combining trust abuse with credential theft for dominance

These actions often occur after initial domain compromise.

---

## 5. Detection Guidance
Detection strategies should focus on:
- Monitoring creation or modification of domain trust objects
- Alerting on trust changes outside approved maintenance windows
- Detecting authentication activity across unusual trust paths
- Correlating trust changes with privilege escalation events

### Data Source Notes
- **Active Directory logs**: Essential for trust change auditing
- **Authentication logs**: Identify anomalous cross-domain access
- **Network telemetry**: Useful for spotting abnormal trust traffic

---

## 6. Response Guidance
When detected:
1. Validate whether trust changes were authorized
2. Revert unauthorized trust modifications immediately
3. Audit all domains impacted by the trust
4. Investigate accounts that gained cross-domain access
5. Review forest-level security posture

## 8. SOC Relevance
T1484.002 is especially relevant in:
- Enterprises with multiple domains or forests
- Mergers and acquisitions environments
- Organizations relying on trust-based access models

Trust abuse enables rapid expansion of attacker control.

---

## 9. Threat Actor Usage
This subtechnique is used by:
- Advanced persistent threats
- Nation-state intrusion sets
- Sophisticated ransomware operators targeting large enterprises

Usage reflects strategic, long-term intrusion objectives.

---

## 10. Campaign Usage
Observed in:
- Domain takeover campaigns
- Long-term enterprise espionage operations
- Attacks targeting cross-forest infrastructure

---

## 11. Malware Usage
Malware leveraging domain trust modification includes:
- Custom Active Directory attack tooling
- Post-exploitation frameworks
- Domain orchestration utilities

---

## 12. Mitigations
Recommended mitigations:
- Strictly limit permissions to manage domain trusts
- Enable detailed auditing for trust changes
- Regularly review and baseline trust configurations
- Monitor cross-domain authentication patterns
- Apply tiered administrative models

---

## 13. Testing & Validation
Validation approaches:
- Simulate unauthorized trust changes in test forests
- Validate SOC alerts for trust object modification
- Conduct red team exercises focused on trust abuse
- Review IR playbooks for cross-domain compromise
