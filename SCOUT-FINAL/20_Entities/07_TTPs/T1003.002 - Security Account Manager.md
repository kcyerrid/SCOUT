## 1. Summary
Security Account Manager (SAM) (T1003.002) is the extraction of local account credential material from the Windows SAM database (typically via registry hive access or in-memory techniques). Attackers generally need elevated (often SYSTEM) privileges to retrieve and decrypt useful credential artifacts.

## 2. Technical Overview
SAM credential dumping typically involves:
- **Registry hive extraction**: Accessing or exporting the SAM and related hives required to derive local account hashes.
- **Offline parsing**: Processing extracted hives/dump artifacts to recover credential material (e.g., NTLM hashes).
- **Volume/shadow-copy access patterns**: Reading protected system files via snapshot or backup mechanisms to avoid direct locks and reduce friction.

Defender-relevant behavior is usually a **sequence**: privilege elevation → sensitive hive access/export → creation of dump artifacts → credential use (local admin reuse or lateral authentication).

## 3. Subtechnique Considerations
- This subtechnique targets **local accounts** (not domain accounts). It is frequently chained with:
  - Local admin password reuse detection (across endpoints)
  - Lateral movement and remote service usage
- Consider host roles: SAM access on **workstations** is common in commodity intrusions; SAM access on **servers/jump hosts** is often higher impact.

## 4. Procedure Examples
Examples documented in ATT&CK include:
- [[30_CIPHER/03_Threat_Actors/G1030 - Agrius]] dumping SAM files for credential capture.
- [[30_CIPHER/03_Threat_Actors/G0016 - APT29]] using registry hive save/export behavior to obtain credential material.
- [[30_CIPHER/03_Threat_Actors/G0096 - APT41]] copying SAM-related hives (including via shadow copy approaches).
- [[30_CIPHER/05_Malware/S0357 - Impacket]] and [[30_CIPHER/05_Malware/S0002 - Mimikatz]] modules used for SAM-related credential extraction.

## 5. Detection Guidance
Prioritize **behavior-chain** detections over single indicators.

High-signal detection patterns:
- **Sensitive hive access/export**
  - Non-admin or unusual admin processes reading/exporting SAM/SYSTEM/SECURITY-related locations.
  - Suspicious registry hive export patterns followed by creation of `.save`, `.hiv`, `.dmp`, or similarly dump-like artifacts.
- **Tool-driven correlations**
  - Execution of known dumping frameworks (where allowed) plus file creation events consistent with hive exports.
  - Process ancestry: Office/browser/script host → privileged tool → hive export/dump artifact.
- **Post-dump credential use**
  - New logons using local accounts (or NTLM-based auth) from the same host shortly after dump artifacts are created.
  - Sudden remote admin activity using local accounts that historically never authenticate remotely.

Triage accelerators:
- “Hive access/export + dump artifact creation + rapid authentication spread” should be treated as **high confidence**.

### Data Source Notes
Useful telemetry sources:
- Endpoint process creation + command-line (EDR/Sysmon-equivalent)
- File creation/access for dump artifacts
- Registry key access auditing (where feasible)
- Privilege and token changes (e.g., SYSTEM context transitions)
- Authentication logs (new local account usage across endpoints)

## 6. Response Guidance
- **Contain**: isolate affected endpoint(s); terminate suspicious processes; block known dumping binaries where appropriate.
- **Credential actions**: rotate local admin passwords (prefer LAPS/managed local admin); reset any accounts suspected of reuse; invalidate sessions where applicable.
- **Scope**: identify all hosts where the same operator/tools executed; hunt for dump artifacts and any outbound staging/exfil.
- **Prevent recurrence**: reduce local admin footprint, restrict who can access protected hives, and harden backup/snapshot permissions.

## 8. SOC Relevance
- **Critical credential event** on Windows endpoints: often enables lateral movement via local admin reuse.
- Best pivots:
  - Identify the dumping process lineage and privilege context
  - Locate dump artifacts and any compression/exfil attempts
  - Correlate to authentication spikes (SMB/RPC/RDP/WMI/WinRM) after the event

## 9. Threat Actor Usage
- Observed across APT and cybercrime; ATT&CK procedure examples include [[30_CIPHER/03_Threat_Actors/G0016 - APT29]] and [[30_CIPHER/03_Threat_Actors/G0096 - APT41]].

## 10. Campaign Usage
- C0051 - APT28 Nearest Neighbor Campaign includes registry hive dumping activity aligned with SAM access for credential harvesting.

## 11. Malware Usage
- [[30_CIPHER/05_Malware/S0002 - Mimikatz]] and [[30_CIPHER/05_Malware/S0357 - Impacket]] include SAM-related credential dumping capabilities.
- [[30_CIPHER/05_Malware/S0488 - CrackMapExec]] can dump SAM-related credential material in some operational contexts.

## 12. Mitigations
- **M1028 - Operating System Configuration**: harden legacy authentication exposure (e.g., reduce NTLM reliance where feasible) and protect sensitive file/registry access paths.
- **M1027 - Password Policies**: enforce strong, unique local admin passwords (managed rotation).
- **M1026 - Privileged Account Management**: minimize SYSTEM/admin exposure; restrict who can obtain high-privilege execution on endpoints.
- **M1017 - User Training**: reduce credential reuse and educate admins about privileged access hygiene.

## 13. Testing & Validation
- In a controlled lab:
  - Simulate SAM/SYSTEM/SECURITY hive access followed by dump artifact creation and verify alert coverage.
  - Validate correlation rules: “hive export” → “dump artifact created” → “new remote authentications” within a short window.
- Build allowlists for approved IR tools to prevent alert fatigue.
