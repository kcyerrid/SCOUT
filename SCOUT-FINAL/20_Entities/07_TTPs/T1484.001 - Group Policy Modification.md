# Domain Policy Modification: Group Policy Modification (T1484.001)

## 1. Summary
This subtechnique describes adversaries **modifying Group Policy Objects (GPOs)** within Active Directory environments to change system or user configurations at scale. By abusing GPOs, attackers can **disable security controls, deploy malicious scripts, grant privileges, or establish persistence** across many systems simultaneously.

T1484.001 is commonly used to:
- Weaken or disable endpoint security controls
- Deploy malicious scripts or executables domain-wide
- Establish persistent access across multiple systems
- Prepare an environment for ransomware or destructive actions

---

## 2. Technical Overview
Group Policy Objects are stored and enforced via:
- Active Directory configuration containers
- SYSVOL file shares replicated across domain controllers

Adversaries abuse GPOs by:
- Editing existing GPOs linked to high-impact OUs
- Creating new malicious GPOs and linking them broadly
- Modifying logon, startup, or scheduled task policies
- Changing security settings, firewall rules, or audit policies

Artifacts often include:
- Unauthorized changes to GPO settings
- File modifications in SYSVOL
- Widespread configuration changes across hosts
- Recurrent policy reapplication overriding local fixes

---

## 3. Subtechnique Considerations
Key considerations for T1484.001:
- Requires domain-level privileges (e.g., Domain Admin)
- Extremely high blast radius
- Often difficult to remediate quickly at scale
- GPO abuse may persist through system reboots

This technique is typically used during later stages of intrusion.

---

## 4. Procedure Examples
Observed adversary procedures include:
- Deploying ransomware loaders via startup scripts
- Disabling antivirus and EDR settings via policy
- Creating scheduled tasks through GPO preferences
- Weakening password, firewall, or logging policies

These actions often precede ransomware execution or data exfiltration.

---

## 5. Detection Guidance
Detection strategies should focus on:
- Monitoring GPO creation, modification, and linking events
- Auditing changes to SYSVOL contents
- Alerting on GPO changes outside approved change windows
- Detecting rapid or broad OU targeting

### Data Source Notes
- **Active Directory logs**: Critical for identifying who made changes
- **SYSVOL monitoring**: Required for detecting file-level modifications
- **Endpoint telemetry**: Useful for confirming policy effects

---

## 6. Response Guidance
When detected:
1. Identify modified GPOs and affected OUs
2. Disable or revert malicious GPOs immediately
3. Investigate accounts responsible for changes
4. Isolate impacted systems if malicious payloads were deployed
5. Review privileged access and GPO delegation permissions

## 8. SOC Relevance
T1484.001 is especially relevant in:
- Large enterprise Active Directory environments
- Ransomware and enterprise-wide intrusion scenarios
- Organizations without strict GPO change management

GPO abuse enables attackers to move faster than traditional IR workflows.

---

## 9. Threat Actor Usage
This subtechnique is widely used by:
- Ransomware operators
- Advanced persistent threats
- Intrusions targeting rapid enterprise-wide control

Usage reflects intent to scale impact quickly.

---

## 10. Campaign Usage
Observed in:
- Ransomware domain takeover campaigns
- Enterprise-wide malware deployments
- Destructive or coercive operations

---

## 11. Malware Usage
Malware leveraging GPO modification includes:
- Ransomware loaders
- Domain-wide backdoors
- Post-exploitation orchestration frameworks

---

## 12. Mitigations
Recommended mitigations:
- Strictly limit and audit GPO modification permissions
- Enable advanced GPO auditing
- Monitor SYSVOL integrity
- Implement tiered administration models
- Require change approval workflows for policy updates

---

## 13. Testing & Validation
Validation approaches:
- Simulate unauthorized GPO modifications in lab domains
- Validate SOC detection of GPO and SYSVOL changes
- Conduct red team exercises focused on domain takeover
- Review backup and restore procedures for GPOs
