# Obfuscated Files or Information: LNK Icon Smuggling (T1027.012)

## 1. Summary
LNK Icon Smuggling describes adversaries **embedding malicious payloads or commands within Windows shortcut (`.lnk`) files while presenting benign or trusted icons**, misleading users and evading basic inspection. The malicious logic is hidden in shortcut properties (such as command-line arguments), while the icon visually suggests a harmless document or application.

Adversaries use this technique to:
- Deceive users into executing malicious shortcuts
- Hide malicious commands behind trusted-looking icons
- Evade superficial file inspection and user scrutiny
- Enable initial access or execution via user interaction

---

## 2. Technical Overview
Windows shortcut files can specify:
- Target executables
- Command-line arguments
- Working directories
- Icons (custom or borrowed from legitimate files)

Adversaries abuse this flexibility by:
- Assigning a legitimate-looking icon (e.g., PDF, folder, Word)
- Embedding malicious commands in arguments or target paths
- Using whitespace, padding, or obfuscation to hide intent
- Pointing to system binaries (LOLBins) with malicious arguments

Common indicators:
- `.lnk` files invoking scripting engines or system utilities
- Mismatch between icon/file name and executed target
- Long or obfuscated command-line arguments in shortcuts
- Shortcut execution followed by script or payload execution

---

## 3. Subtechnique Considerations
Key considerations for T1027.012:
- Strongly associated with **User Execution (T1204)**
- Often delivered via **Phishing (T1566)** or removable media
- Highly effective against non-technical users
- Windows-specific but broadly applicable in enterprise environments

This technique blends **social engineering with technical obfuscation**.

---

## 4. Procedure Examples
Representative adversary behaviors include:
- Delivering ZIP archives containing malicious LNK files
- Using folder icons to disguise executable shortcuts
- Embedding PowerShell or CMD arguments in LNK targets
- Naming shortcuts to mimic documents or folders

*(Examples are representative and intentionally non-operational.)*

---

## 5. Detection Guidance
Detection should emphasize **shortcut behavior and execution context**:
- Alert on `.lnk` files executing scripting engines or LOLBins
- Detect mismatches between shortcut icon/type and target
- Monitor command-line arguments launched by Explorer
- Correlate shortcut execution with follow-on activity

### Data Source Notes
- **File monitoring**: Identify suspicious LNK creation or delivery
- **Process logs**: Capture execution via `explorer.exe`
- **Email gateway logs**: Identify LNK attachments or archives

Common false positives:
- Legitimate administrative shortcuts
- Software installers using shortcuts

Tuning guidance:
- Baseline expected LNK usage
- Elevate alerts when shortcuts launch interpreters or network activity

---

## 6. Response Guidance
When suspected:
1. Quarantine the malicious LNK file
2. Inspect shortcut properties and embedded commands
3. Identify any follow-on payloads or scripts
4. Hunt for similar LNK artifacts across the environment
5. Block delivery channels and educate affected users

## 8. SOC Relevance
T1027.012 is critical because:
- Visual deception bypasses many technical controls
- Execution is user-driven and context-dependent
- Initial access may appear benign

SOC teams should treat **LNK execution with scrutiny**, especially from untrusted sources.

---

## 9. Threat Actor Usage
Commonly used by:
- Initial access brokers
- Malware delivery operations
- Ransomware affiliates

---

## 10. Campaign Usage
Observed in:
- Phishing campaigns delivering ZIP/LNK payloads
- Malware loader distribution operations
- Early-stage intrusion chains

---

## 11. Malware Usage
Associated with:
- Loaders and droppers
- Script-based malware
- Ransomware delivery mechanisms

---

## 12. Mitigations
Recommended mitigations:
- Block or restrict LNK attachments from email
- Disable execution of shortcuts from untrusted locations
- Educate users about deceptive icons
- Monitor Explorer-launched processes

---

## 13. Testing & Validation
Validation approaches:
- Deliver benign LNK samples in test environments
- Validate alerts on shortcut execution
- Test SOC playbooks for LNK-based initial access
- Ensure tooling captures full shortcut metadata
