# T1543.004 – Launch Daemon

## 1. Technique Overview
**Launch Daemon (T1543.004)** is a sub-technique of **Create or Modify System Process (T1543)** in **MITRE ATT&CK v18**. Adversaries abuse **launchd Launch Daemons** to establish persistence by configuring attacker-controlled programs to execute automatically during system boot or in response to defined system conditions.

Unlike Launch Agents, Launch Daemons run **outside of user context** and typically execute with **root privileges**, making this technique particularly powerful for both persistence and privilege escalation on macOS systems.

## 2. Adversary Objectives
Adversaries use Launch Daemons to:
- Maintain persistence across system reboots
- Execute malicious code with elevated (root) privileges
- Blend persistence into native macOS service management
- Regain execution after remediation efforts

## 3. Common Abuse Patterns
- Creating malicious `.plist` files in:
  - `/Library/LaunchDaemons`
  - `/System/Library/LaunchDaemons` (less common due to protections)
- Configuring `RunAtLoad` or `KeepAlive` keys for execution control
- Pointing `ProgramArguments` to attacker-controlled binaries or scripts
- Masquerading daemon labels and filenames as legitimate system services
- Using launchd triggers to restart malicious payloads automatically

## 4. Detection Considerations
Detection relies on **file integrity, configuration, and process monitoring**, including:
- Monitoring creation or modification of `.plist` files in LaunchDaemons directories
- Detecting Launch Daemons referencing unusual or user-writable paths
- Correlating system boot events with unexpected daemon execution
- Auditing enabled Launch Daemons against known-good baselines
- Reviewing launchd logs for anomalous daemon activity

## 5. Defensive Mitigations
- Restrict write access to LaunchDaemons directories
- Monitor Launch Daemon configurations with file integrity controls
- Use endpoint security tooling with macOS persistence visibility
- Enforce System Integrity Protection (SIP) where possible
- Investigate and remove unauthorized Launch Daemons promptly

## 6. Operational Impact
If successful, T1543.004 can:
- Provide durable, root-level persistence
- Enable execution early in the system lifecycle
- Evade user-focused persistence detection mechanisms
- Complicate remediation due to elevated execution context

## 7. Analyst Notes
Launch Daemons represent one of the most reliable and stealthy macOS persistence mechanisms due to their privileged execution and integration with launchd. During incident response, analysts should enumerate **all Launch Daemons**, validate the provenance of referenced binaries, and correlate creation times with initial access events.
