# T1037.001 – Logon Script (Windows)

## 1. Technique Overview
**Logon Script (Windows) (T1037.001)** is a sub-technique of **Boot or Logon Initialization Scripts (T1037)** in **MITRE ATT&CK v18**. Adversaries abuse Windows **logon scripts**, which are executed automatically when a user authenticates, to achieve persistence or run malicious commands in the context of the logging-in user.

In enterprise environments, logon scripts are often centrally managed through **Active Directory Group Policy**, making them a high-impact persistence mechanism when compromised.

## 2. Adversary Objectives
Adversaries use logon scripts to:
- Maintain persistence tied to user authentication
- Execute payloads automatically at each logon
- Leverage trusted administrative infrastructure
- Regain execution after system restarts

## 3. Common Abuse Patterns
- Modifying existing logon scripts managed by Group Policy
- Adding malicious commands to batch, PowerShell, or VBScript files
- Creating new logon scripts and assigning them to users or groups
- Hosting malicious scripts on network shares referenced by policies
- Masquerading script logic as legitimate administrative tasks

## 4. Detection Considerations
Detection relies on **directory, file, and script monitoring**, including:
- Monitoring changes to logon script files and locations
- Auditing Group Policy Objects (GPOs) for script modifications
- Detecting execution of unexpected commands during user logon
- Correlating logon events with script-driven process execution
- Reviewing network access to script-hosting shares

## 5. Defensive Mitigations
- Restrict write access to logon script directories and shares
- Monitor and alert on GPO modifications related to scripts
- Enforce script signing and execution policies
- Audit logon scripts regularly for unauthorized changes
- Use least privilege for administrative accounts managing GPOs

## 6. Operational Impact
If successful, T1037.001 can:
- Provide durable, user-context persistence
- Affect multiple systems and users simultaneously
- Enable execution without additional user interaction
- Complicate remediation due to centralized management

## 7. Analyst Notes
Logon script abuse is especially dangerous in Active Directory environments because it can scale rapidly across large user populations. During incident response, analysts must review **both script contents and GPO assignments**, as attackers may leave scripts intact but alter which users or systems receive them.
