# T1546.001 – Change Default File Association

## 1. Technique Overview
**Change Default File Association (T1546.001)** is a sub-technique of **Event Triggered Execution (T1546)** in **MITRE ATT&CK v18**. Adversaries abuse the Windows file association mechanism so that opening a particular file type (e.g., `.txt`, `.docx`, `.pdf`) results in the execution of attacker-controlled code rather than the legitimate application.

This technique leverages a trusted user action—opening a file—to trigger execution, enabling persistence and potentially privilege escalation while minimizing behavioral noise.

## 2. Adversary Objectives
Adversaries use this technique to:
- Establish user-driven persistence
- Execute malicious payloads in response to normal user activity
- Evade detection by avoiding continuous background execution
- Blend malicious execution into legitimate file-handling behavior

## 3. Common Abuse Patterns
- Modifying file association registry keys under:
  - `HKCU\Software\Classes`
  - `HKLM\Software\Classes`
- Hijacking `Open` command handlers for common file extensions
- Redirecting file open actions to malicious executables or scripts
- Masquerading malicious handlers as legitimate applications
- Targeting frequently used file types to ensure reliable execution

## 4. Detection Considerations
Detection relies on **registry and behavior monitoring**, including:
- Monitoring changes to file association registry keys
- Alerting on unexpected command changes for common file extensions
- Correlating file-open events with execution of anomalous processes
- Comparing file association configurations against known-good baselines
- Detecting user-level association changes outside normal workflows

## 5. Defensive Mitigations
- Restrict permissions to modify system-wide file associations
- Monitor registry locations responsible for file handling
- Enforce application allowlisting for file handlers
- Regularly audit file association configurations
- Restore default associations during incident response

## 6. Operational Impact
If successful, T1546.001 can:
- Provide reliable execution tied to user behavior
- Evade detection mechanisms focused on startup persistence
- Enable execution without exploiting vulnerabilities
- Complicate detection due to legitimate trigger conditions

## 7. Analyst Notes
File association hijacking is effective because it exploits implicit user trust in file handling. During investigations, analysts should enumerate **both user-level and system-level file associations**, as attackers often prefer per-user changes to avoid administrative privileges and reduce visibility.
