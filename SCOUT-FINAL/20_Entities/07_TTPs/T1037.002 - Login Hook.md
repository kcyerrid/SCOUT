# T1037.002 – Login Hook

## 1. Technique Overview
**Login Hook (T1037.002)** is a sub-technique of **Boot or Logon Initialization Scripts (T1037)** in **MITRE ATT&CK v18**. Adversaries abuse macOS **login hooks**, which are scripts or executables configured to run automatically when a user logs in. When present, these hooks execute with elevated trust as part of the login workflow.

Although Apple has deprecated login hooks in modern macOS versions, they may still be present on legacy systems or misconfigured environments, making them a viable persistence mechanism in certain scenarios.

## 2. Adversary Objectives
Adversaries use login hooks to:
- Maintain persistence across user logins
- Execute malicious code as part of a trusted login process
- Avoid more commonly monitored autostart locations
- Regain execution after system restarts

## 3. Common Abuse Patterns
- Configuring a login hook using `defaults write com.apple.loginwindow LoginHook`
- Pointing the LoginHook to attacker-controlled scripts or binaries
- Masquerading hook scripts as legitimate administrative tasks
- Combining login hooks with additional persistence mechanisms
- Using hooks to deploy secondary payloads at login

## 4. Detection Considerations
Detection relies on **configuration and process monitoring**, including:
- Auditing `com.apple.loginwindow` preferences for LoginHook entries
- Detecting execution of unexpected scripts at user login
- Correlating login events with suspicious process launches
- Monitoring legacy persistence mechanisms on older macOS versions
- Reviewing system configuration profiles for unauthorized changes

## 5. Defensive Mitigations
- Remove or disable login hooks where present
- Audit macOS systems for deprecated persistence mechanisms
- Restrict administrative privileges required to configure login hooks
- Use endpoint security tools with macOS persistence visibility
- Reimage systems where unauthorized login hooks are discovered

## 6. Operational Impact
If successful, T1037.002 can:
- Provide durable user-level persistence
- Enable execution within trusted login workflows
- Evade detection in environments focused on modern persistence methods
- Increase dwell time on affected macOS systems

## 7. Analyst Notes
Login hooks are largely deprecated but remain relevant for incident response on **legacy macOS systems** or environments that have not fully modernized security controls. Analysts should explicitly check for LoginHook and LogoutHook configurations when investigating unexplained persistence on macOS.
