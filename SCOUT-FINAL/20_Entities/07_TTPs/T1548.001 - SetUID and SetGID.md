# Abuse Elevation Control Mechanism: Setuid and Setgid (T1548.001)

## 1. Summary
This subtechnique describes adversaries abusing **set-user-ID (setuid)** and **set-group-ID (setgid)** permission bits on Unix-like operating systems to execute binaries with elevated privileges. These mechanisms are designed to allow limited privilege escalation for legitimate system functions, but misconfigurations or vulnerable binaries can allow attackers to escalate privileges to root or other high-privilege accounts.

T1548.001 is commonly used after initial access to:
- Escalate privileges from a low-privilege user
- Bypass authorization controls
- Enable credential access, persistence, or lateral movement

---

## 2. Technical Overview
On Linux and macOS systems, binaries with the setuid or setgid bit execute with the permissions of the file owner or group rather than the invoking user. Adversaries exploit this behavior by:
- Identifying misconfigured setuid/setgid binaries
- Exploiting vulnerable or outdated privileged binaries
- Leveraging unsafe environment variable handling
- Abusing writable scripts or interpreters executed in a privileged context

Technical artifacts often include:
- Execution of uncommon privileged binaries
- Abuse of interpreters (e.g., shells, scripting runtimes) with setuid bits
- Unexpected root-level process creation originating from user sessions

---

## 3. Subtechnique Considerations
Key considerations for T1548.001 include:
- Setuid/setgid abuse is platform-specific (Linux/macOS)
- Risk increases significantly when custom or third-party binaries are marked setuid
- Containers and hardened systems may reduce but not eliminate risk
- Cloud-hosted Linux systems frequently inherit insecure defaults

Organizations should inventory all setuid/setgid binaries and evaluate their necessity.

---

## 4. Procedure Examples
Observed adversary procedures include:
- Enumerating setuid/setgid binaries using filesystem discovery
- Executing vulnerable utilities to spawn privileged shells
- Exploiting environment variable inheritance (e.g., `PATH`, `LD_PRELOAD`)
- Chaining setuid abuse with kernel exploits for reliability

These actions typically occur rapidly after initial access.

---

## 5. Detection Guidance
Detection strategies should focus on:
- Monitoring execution of setuid/setgid binaries by non-administrative users
- Identifying rare or newly modified privileged binaries
- Correlating privilege escalation with prior filesystem discovery activity
- Alerting on unexpected root process ancestry

### Data Source Notes
- **Process telemetry**: High value for detecting privilege transitions
- **File metadata**: Useful for spotting permission changes
- **Audit logs**: Often incomplete unless explicitly enabled

---

## 6. Response Guidance
When detected:
1. Confirm whether execution aligns with legitimate administrative activity
2. Identify the abused binary and its permission settings
3. Remove or restrict unsafe setuid/setgid permissions
4. Investigate for follow-on actions (credential dumping, persistence)
5. Rotate credentials if root access was obtained

## 8. SOC Relevance
T1548.001 is particularly relevant in:
- Linux server environments
- Cloud-hosted virtual machines
- Container breakout scenarios
- Legacy Unix systems with custom binaries

Privilege escalation on Unix-like systems often goes undetected without explicit monitoring.

---

## 9. Threat Actor Usage
This subtechnique is widely used by:
- Ransomware operators targeting Linux servers
- Cloud-focused intrusion sets
- Advanced persistent threats performing post-exploitation escalation

Usage is opportunistic and heavily dependent on system configuration.

---

## 10. Campaign Usage
T1548.001 appears in:
- Targeted Linux server compromises
- Cloud environment intrusions
- Multi-stage ransomware campaigns prior to encryption

---

## 11. Malware Usage
Malware leveraging this technique often includes:
- Linux backdoors
- Post-exploitation privilege escalation helpers
- Custom scripts bundled with exploit frameworks

---

## 12. Mitigations
Recommended mitigations include:
- Auditing and minimizing setuid/setgid binaries
- Removing unnecessary privileged permissions
- Applying OS and application patches
- Using mandatory access control (SELinux, AppArmor)
- Monitoring privileged execution paths

---

## 13. Testing & Validation
Validation approaches:
- Enumerate setuid/setgid binaries and simulate misuse
- Use Atomic Red Team tests for T1548.001
