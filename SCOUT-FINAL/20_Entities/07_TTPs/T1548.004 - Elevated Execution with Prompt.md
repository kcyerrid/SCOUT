# Abuse Elevation Control Mechanism: Elevated Execution with Prompt (T1548.004)

## 1. Summary
This subtechnique describes adversaries obtaining elevated privileges by **prompting a user for consent or credentials** through legitimate elevation dialogs. Unlike silent bypasses, this technique relies on **user interaction**, exploiting trust in system prompts or manipulating users into approving privileged execution.

T1548.004 is commonly observed in:
- Social engineering–driven intrusions
- Initial stages of ransomware deployment
- Malware campaigns relying on user execution

---

## 2. Technical Overview
Operating systems require explicit user approval for certain privileged actions:
- Windows uses UAC prompts
- macOS uses authorization dialogs for administrative actions

Adversaries abuse these mechanisms by:
- Executing binaries that legitimately trigger elevation prompts
- Presenting deceptive context to coerce approval
- Bundling malicious payloads with trusted installers or scripts
- Leveraging signed or benign-appearing binaries to reduce suspicion

Artifacts typically include:
- User-approved elevated process creation
- Authentication or consent events followed immediately by suspicious activity
- Elevated execution originating from user-space applications

---

## 3. Subtechnique Considerations
Key considerations for T1548.004:
- Requires direct user interaction
- Effectiveness depends on user awareness and security training
- More common in phishing or trojanized software delivery
- Harder to distinguish from legitimate administrative activity

This technique is less stealthy but often highly effective in real-world environments.

---

## 4. Procedure Examples
Observed adversary procedures include:
- Delivering trojanized installers that request elevation
- Using scripting interpreters that prompt for admin rights
- Leveraging fake error dialogs or update prompts
- Executing ransomware binaries that rely on user-approved elevation

These procedures frequently follow phishing or drive-by download campaigns.

---

## 5. Detection Guidance
Detection strategies should focus on:
- Monitoring elevated executions following user interaction
- Correlating UAC or authorization prompts with suspicious binaries
- Detecting rare parent–child process relationships involving installers
- Alerting on elevated execution immediately after file download or email access

### Data Source Notes
- **Process telemetry**: Essential for tracing execution chains
- **UI events / auth logs**: Useful for confirming user approval
- **Email and web logs**: Help correlate delivery vectors

---

## 6. Response Guidance
When detected:
1. Determine whether the elevation was intentional and legitimate
2. Identify the binary or script that triggered the prompt
3. Quarantine affected systems if malicious activity is confirmed
4. Investigate for follow-on actions (persistence, lateral movement)
5. Provide user awareness feedback if social engineering was involved

## 8. SOC Relevance
T1548.004 is highly relevant where:
- Users frequently install software
- Local administrator rights are common
- Security awareness maturity is low

User-approved elevation is a frequent precursor to ransomware execution.

---

## 9. Threat Actor Usage
This technique is widely used by:
- Ransomware affiliates
- Commodity malware distributors
- Social-engineering-focused threat groups

Adversaries often favor this method when silent escalation is unavailable.

---

## 10. Campaign Usage
Observed in:
- Phishing-driven ransomware campaigns
- Fake software update operations
- Trojanized installer delivery campaigns

---

## 11. Malware Usage
Malware commonly leveraging this technique includes:
- Ransomware families
- Loaders delivered via phishing
- Trojanized installers and scripts

---

## 12. Mitigations
Recommended mitigations:
- Reduce local administrator privileges
- Harden UAC and authorization settings
- Implement application allow-listing
- Strengthen user security awareness training
- Monitor and restrict installer execution

---

## 13. Testing & Validation
Validation approaches:
- Simulate trojanized installer execution
- Test SOC response to user-approved elevation events
- Use Atomic Red Team tests aligned to T1548.004
- Conduct phishing and social engineering tabletop exercises
