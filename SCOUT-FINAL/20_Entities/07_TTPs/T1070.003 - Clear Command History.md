# Indicator Removal on Host: Clear Command History (T1070.003)

## 1. Summary
Clear Command History describes adversaries **removing previously recorded command-line history** to eliminate evidence of executed commands. This subtechnique targets shell and interpreter history artifacts that analysts rely on to reconstruct attacker actions.

Attackers use this technique to:
- Obscure executed commands
- Hinder forensic analysis
- Reduce attribution detail
- Complement other anti-forensic activity

---

## 2. Technical Overview
Most operating systems and shells store command history locally. Adversaries clear this history by:

- Deleting or truncating history files
- Clearing in-memory command history
- Overwriting history content
- Removing interpreter-specific history records

Platform-specific considerations:
- **Linux/macOS**: Bash/Zsh history files
- **Windows PowerShell**: PSReadLine history
- **Cross-platform**: Clearing interpreter session history

Indicators include:
- Missing or empty history files
- History cleared shortly after suspicious activity
- Command execution without corresponding history entries

---

## 3. Subtechnique Considerations
Key considerations for T1070.003:
- Often paired with **Impair Command History Logging (T1562.003)**
- Common in hands-on-keyboard intrusions
- Requires local access to affected system
- Reduces post-incident reconstruction fidelity

This technique focuses on **removal after the fact**, not prevention.

---

## 4. Procedure Examples
Representative adversary behaviors include:
- Clearing shell history after executing commands
- Removing PowerShell history records
- Automating history cleanup post-exploitation
- Deleting interpreter history files before disconnecting

*(Examples are representative and intentionally non-operational.)*

---

## 5. Detection Guidance
Detection should focus on **history file integrity**:
- Monitor history file deletion or truncation
- Alert on sudden changes to history size
- Correlate history clearing with suspicious execution
- Detect commands executed without corresponding history

### Data Source Notes
- **File system monitoring**: Detect history file changes
- **EDR telemetry**: Capture command execution independently
- **Process telemetry**: Identify interactive shell usage

Common false positives:
- Privacy-conscious users clearing history
- Automated scripts or ephemeral sessions

Tuning guidance:
- Baseline history behavior by user role
- Elevate alerts when history clearing coincides with other suspicious activity

---

## 6. Response Guidance
When suspected:
1. Preserve remaining history artifacts immediately
2. Correlate execution with alternate telemetry sources
3. Investigate for additional defense evasion techniques
4. Expand scope to identify similar activity on other hosts

## 12. Mitigations
Recommended mitigations:
- Use EDR to capture command execution independently
- Centralize command logging where feasible
- Monitor for history file tampering
- Limit interactive shell access
- Train analysts to recognize history gaps

## 13. Testing & Validation
Validation approaches:
- Clear command history in lab environments
- Validate alerts on history file deletion
- Test SOC workflows for incomplete command timelines
- Ensure alternate telemetry fills gaps
