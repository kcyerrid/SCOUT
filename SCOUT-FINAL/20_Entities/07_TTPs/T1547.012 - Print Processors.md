# T1547.012 – Print Processors

## 1. Technique Overview
**Print Processors (T1547.012)** is a sub-technique of **Boot or Logon Autostart Execution (T1547)** in MITRE ATT&CK v18. Adversaries abuse Windows **print processors**, which are implemented as DLLs loaded by the **Print Spooler service** when processing print jobs. By registering a malicious print processor, attacker-controlled code is executed in a **privileged service context**.

This technique provides durable persistence and may also support privilege escalation.

## 2. Adversary Objectives
Adversaries use this technique to:
- Achieve persistent execution tied to print activity
- Run code within the Print Spooler service context
- Blend malicious activity into legitimate print operations
- Support follow-on actions such as credential access or lateral movement

## 3. Common Abuse Patterns
- Registering malicious print processor DLLs via:
  - `HKLM\SYSTEM\CurrentControlSet\Control\Print\Environments\Windows x64\Print Processors`
- Masquerading malicious DLLs as legitimate print components
- Triggering execution via normal or forced print jobs
- Pairing print processor persistence with other spooler abuses
- Deploying this technique on systems with active printing services

## 4. Detection Considerations
Detection requires **print subsystem and DLL load monitoring**, including:
- Monitoring changes to print processor registry keys
- Detecting new or unsigned DLLs loaded by `spoolsv.exe`
- Alerting on print processor additions outside approved printer installations
- Correlating print job activity with suspicious DLL execution
- Auditing print subsystem configuration during investigations

## 5. Defensive Mitigations
- Disable the Print Spooler service where printing is not required
- Restrict administrative privileges needed to modify printer configurations
- Monitor integrity of print processor registry entries and DLLs
- Enforce code signing and application allowlisting
- Treat unauthorized print processor changes as critical incidents

## 6. Operational Impact
If successful, T1547.012 can:
- Provide persistent, high-privilege execution
- Enable stealthy malware operation via legitimate services
- Facilitate additional malicious activity
- Complicate detection due to the obscurity of print subsystem internals

## 7. Analyst Notes
Print processor abuse is a **low-frequency but high-impact** persistence mechanism. Many organizations lack visibility into print subsystem configuration, making this technique attractive to advanced adversaries. During response, analysts should explicitly review print processor registrations when investigating unexplained privileged persistence.
