# T1556.003 – Pluggable Authentication Modules

## 1. Technique Overview
**Pluggable Authentication Modules (T1556.003)** is a sub-technique of [[20_Entities/07_TTPs/T1556 - Modify Authentication Process|T1556]] in **MITRE ATT&CK v18**. Adversaries abuse the **PAM framework**, which provides a modular mechanism for authentication on Linux and Unix-like systems, by inserting or modifying modules that are executed during authentication events such as login, `sudo`, or remote access.

Because PAM modules execute as part of core authentication workflows—often with elevated privileges—this technique enables highly reliable credential interception and durable persistence.

## 2. Adversary Objectives
Adversaries use PAM abuse to:
- Capture plaintext credentials during authentication
- Bypass or weaken authentication controls
- Maintain persistent access despite credential changes
- Operate stealthily within trusted system components

## 3. Common Abuse Patterns
- Installing malicious PAM modules in standard PAM directories
- Modifying PAM configuration files to load attacker-controlled modules
- Hooking authentication, account, session, or password management stacks
- Logging or exfiltrating credentials during login or privilege escalation
- Targeting SSH, console login, or `sudo` authentication flows

## 4. Detection Considerations
Detection relies on **configuration integrity and authentication monitoring**, including:
- Monitoring changes to PAM configuration files (e.g., under `/etc/pam.d/`)
- Auditing installed PAM modules for unauthorized additions
- Correlating authentication events with unexpected file or network activity
- Applying file integrity monitoring to PAM libraries and configs
- Reviewing authentication logs for anomalous patterns

## 5. Defensive Mitigations
- Restrict write access to PAM configuration files and module directories
- Monitor and alert on PAM configuration or module changes
- Enforce least privilege for system administration accounts
- Use file integrity monitoring on authentication components
- Rebuild affected systems if malicious PAM modules are identified

## 6. Operational Impact
If successful, T1556.003 can:
- Enable persistent, high-fidelity credential harvesting
- Undermine trust in system authentication mechanisms
- Persist across reboots and credential resets
- Require system-wide credential hygiene and remediation

## 7. Analyst Notes
Malicious PAM modules are a **high-severity indicator of compromise** on Unix-like systems. Analysts should assume deep system access and prioritize containment, credential rotation, and verification of all authentication pathways when PAM abuse is discovered.
