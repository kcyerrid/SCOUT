# Indicator Removal on Host: Timestomp (T1070.006)

## 1. Summary
Timestomp describes adversaries **modifying file timestamps** to disguise the true creation, modification, or access times of malicious artifacts. By altering metadata, attackers reduce the effectiveness of timeline-based forensic analysis and blend malicious files into benign system activity.

Attackers use timestomping to:
- Obscure when malware was introduced
- Evade file-age–based detections
- Blend artifacts into baseline system timelines
- Complicate forensic reconstruction

---

## 2. Technical Overview
Modern filesystems track multiple timestamps, commonly:
- Creation time
- Modification time
- Access time
- Metadata change time

Adversaries manipulate these timestamps by:
- Directly modifying file metadata via OS APIs
- Copying timestamps from benign system files
- Resetting timestamps to historical values
- Aligning timestamps with system installation dates

This technique is effective across:
- NTFS (Windows)
- ext4/XFS (Linux)
- APFS/HFS+ (macOS)

Indicators include:
- Files with implausible timestamp values
- Timestamp clusters inconsistent with activity
- Creation times earlier than system installation
- Identical timestamps across unrelated files

---

## 3. Subtechnique Considerations
Key considerations for T1070.006:
- Often follows **Ingress Tool Transfer (T1105)** or payload deployment
- Frequently paired with **Hide Artifacts (T1564)**
- Impacts forensic timelines rather than execution itself
- May be automated in malware toolchains

Timestomp is most effective when defenders rely heavily on timestamp correlation.

---

## 4. Procedure Examples
Representative adversary behaviors include:
- Resetting timestamps after dropping a payload
- Copying timestamps from legitimate system binaries
- Normalizing timestamps across staged files
- Modifying access times to avoid “recently used” indicators

*(Examples are representative and intentionally non-operational.)*

---

## 5. Detection Guidance
Detection should focus on **metadata anomalies**:
- Alert on files with timestamps outside plausible ranges
- Detect mismatches between file timestamps and system events
- Correlate file creation with execution telemetry
- Identify timestamp clusters inconsistent with baselines

### Data Source Notes
- **File metadata monitoring**: Primary detection source
- **EDR telemetry**: Correlate execution and file operations
- **Forensic tooling**: Identify metadata inconsistencies

Common false positives:
- File copying during system migrations
- Backup and restore operations
- Application installers normalizing timestamps

Tuning guidance:
- Baseline timestamp behavior per host type
- Increase severity when timestomp coincides with suspicious execution

---

## 6. Response Guidance
When suspected:
1. Identify files with anomalous timestamps
2. Correlate metadata with execution and network activity
3. Preserve file system metadata immediately
4. Recover original timestamps where possible
5. Expand hunt for similarly modified files

## 8. SOC Relevance
T1070.006 is especially relevant when:
- Malware artifacts appear older than expected
- Incident timelines do not align with known access
- File age–based detections fail unexpectedly

It frequently explains **timeline deception** in investigations.

---

## 9. Threat Actor Usage
Commonly used by:
- Advanced persistent threats
- Ransomware operators
- Malware families with anti-forensic capabilities

---

## 10. Campaign Usage
Observed in:
- Long-dwell espionage operations
- Ransomware staging phases
- Intrusions emphasizing stealth and cleanup

---

## 11. Malware Usage
Associated with:
- Advanced loaders and backdoors
- Ransomware affiliates
- Custom implants with forensic evasion features

---

## 12. Mitigations
Recommended mitigations:
- Correlate file timestamps with execution telemetry
- Use immutable logging for file operations
- Detect impossible or inconsistent timestamp values
- Apply EDR rules for timestamp manipulation APIs

---

## 13. Testing & Validation
Validation approaches:
- Modify timestamps of benign files in lab environments
- Validate alerts on timestamp anomalies
- Test forensic workflows for timeline manipulation
- Ensure SOC analysts recognize timestomp indicators
