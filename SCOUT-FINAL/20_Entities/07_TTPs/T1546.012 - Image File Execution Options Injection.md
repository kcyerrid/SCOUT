# T1546.012 – Image File Execution Options Injection

## 1. Technique Overview
**Image File Execution Options Injection (T1546.012)** is a sub-technique of **Event Triggered Execution (T1546)** in **MITRE ATT&CK v18**. Adversaries abuse the Windows **Image File Execution Options (IFEO)** registry mechanism to alter how specific executables are launched. By configuring debugger or process redirection settings, attackers can cause malicious code to execute whenever a targeted application starts.

This technique leverages a legitimate Windows debugging feature and enables precise, application-specific execution control.

## 2. Adversary Objectives
Adversaries use IFEO injection to:
- Achieve execution tied to specific application launches
- Redirect legitimate programs to attacker-controlled binaries
- Maintain persistence without traditional startup mechanisms
- Evade detection by exploiting trusted debugging infrastructure

## 3. Common Abuse Patterns
- Creating or modifying registry keys under:
  - `HKLM\Software\Microsoft\Windows NT\CurrentVersion\Image File Execution Options`
- Setting the `Debugger` value to point to a malicious executable
- Targeting commonly used or security-sensitive applications
- Masquerading malicious debugger paths as legitimate tools
- Using IFEO for both persistence and denial-of-service effects

## 4. Detection Considerations
Detection relies on **registry, process creation, and behavior monitoring**, including:
- Monitoring creation or modification of IFEO registry keys
- Alerting on unexpected `Debugger` values
- Correlating application launch failures or redirection with registry changes
- Auditing systems for non-default IFEO configurations
- Detecting debugger execution chains tied to common applications

## 5. Defensive Mitigations
- Restrict permissions required to configure IFEO settings
- Monitor and alert on IFEO registry modifications
- Enforce application allowlisting and code signing
- Regularly audit IFEO entries across endpoints
- Remove unauthorized IFEO configurations during incident response

## 6. Operational Impact
If successful, T1546.012 can:
- Provide precise, application-triggered persistence
- Enable execution within trusted execution chains
- Disrupt or hijack legitimate software behavior
- Complicate forensic timelines due to indirect execution

## 7. Analyst Notes
IFEO abuse is powerful because it enables **deterministic execution** tied to specific binaries. Analysts should treat any non-default IFEO entries as suspicious and include IFEO enumeration as a standard step in Windows persistence investigations.
