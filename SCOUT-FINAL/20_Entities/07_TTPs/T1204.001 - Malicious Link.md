# Malicious Link (T1204.001)

## 1. Summary
Malicious Link describes adversaries relying on a user clicking a hyperlink that leads to the execution of malicious content. This may include links that download malware, redirect to exploit kits, trigger script execution, or initiate authentication-based attacks.

This subtechnique is a cornerstone of phishing, social engineering, and initial execution chains and frequently precedes malware installation or credential compromise.

---

## 2. Technical Overview
Malicious links are typically delivered through:
- Phishing emails
- SMS or messaging platforms
- Social media posts
- Compromised or malicious websites

Upon user interaction, links may:
- Download executable or script files
- Redirect to exploit delivery infrastructure
- Trigger browser-based execution
- Abuse URL handlers or protocol schemes

Artifacts include browser process execution, network requests to malicious domains, downloaded files, and subsequent execution events.

---

## 3. Subtechnique Considerations
T1204.001 differs from other User Execution subtechniques by emphasizing *link-based* initiation rather than file opening.

Key considerations include:
- Use of URL shorteners or redirects
- Domain spoofing and lookalike URLs
- Abuse of trusted services (cloud storage, collaboration platforms)
- Variability in execution behavior depending on payload type

Detection requires visibility across email, browser, and endpoint layers.

---

## 4. Procedure Examples
Observed adversary procedures include:
- Sending phishing emails with links to malware-hosting pages
- Redirecting users through multiple benign-looking domains
- Using links to trigger drive-by downloads
- Leveraging links to initiate OAuth or credential harvesting flows

Analysts may observe execution shortly after browser navigation events.

---

## 5. Detection Guidance
Detection should focus on:
- Browser navigation to newly registered or suspicious domains
- Execution of downloaded files immediately after link clicks
- Correlation between email links and endpoint execution
- Network requests associated with known phishing infrastructure

Combining email security telemetry with endpoint activity significantly improves detection.

### Data Source Notes
- **Browser History:** Critical for tracing user interaction
- **Network Traffic:** Identifies malicious infrastructure
- **Email Logs:** Provide delivery and context of malicious links

---

## 6. Response Guidance
When malicious link execution is suspected:
- Identify and block the malicious URL across controls
- Isolate affected endpoints if execution occurred
- Capture downloaded payloads and browser artifacts
- Review user authentication activity for compromise

Preserve email, browser, and endpoint telemetry for investigation.

## 8. SOC Relevance
Malicious link execution is one of the most common execution vectors observed by SOCs. High alert volumes necessitate correlation-based detection rather than simple IOC matching.

---

## 9. Threat Actor Usage
This subtechnique is used by:
- Commodity malware operators
- Ransomware affiliates
- Initial access brokers
- Advanced persistent threat groups

Confidence in ubiquitous usage is extremely high.

## 12. Mitigations
Effective mitigations include:
- Email and web gateway URL filtering
- User security awareness training
- Browser isolation and sandboxing
- Blocking execution from download directories
- Continuous domain reputation monitoring

---

## 13. Testing & Validation
Validation approaches include:
- Phishing simulation exercises using link-based payloads
- Purple team testing correlating click-to-execution
- Review of alerts tied to malicious navigation events

Successful validation results in detection of unauthorized execution following link clicks.
