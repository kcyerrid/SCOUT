# T1546.004 – Unix Shell Configuration Modification

## 1. Technique Overview
**Unix Shell Configuration Modification (T1546.004)** is a sub-technique of **Event Triggered Execution (T1546)** in **MITRE ATT&CK v18**. Adversaries abuse shell initialization files that are automatically executed when a user starts a shell session, enabling malicious commands to run without explicit user action.

This technique targets interactive and non-interactive shell startup behavior across Unix-like operating systems.

## 2. Adversary Objectives
Adversaries use shell configuration modification to:
- Establish user-level persistence
- Execute payloads during routine shell usage
- Blend malicious commands into legitimate configuration files
- Avoid traditional startup persistence mechanisms

## 3. Common Abuse Patterns
- Modifying shell initialization files such as:
  - `~/.bashrc`
  - `~/.bash_profile`
  - `~/.profile`
  - `~/.zshrc`
- Appending malicious commands or sourcing attacker-controlled scripts
- Using conditional logic to execute only in specific environments
- Masquerading malicious content as legitimate aliases or environment variables
- Targeting multiple shell types to increase execution coverage

## 4. Detection Considerations
Detection relies on **file integrity and user behavior monitoring**, including:
- Monitoring changes to shell configuration files
- Alerting on unexpected additions to initialization scripts
- Correlating shell startup with execution of anomalous commands
- Comparing shell configuration files against known-good baselines
- Reviewing sourced scripts referenced by shell configs

## 5. Defensive Mitigations
- Restrict write permissions to user and system shell configuration files
- Monitor shell initialization files with integrity controls
- Use endpoint detection tools that capture shell startup behavior
- Educate users to report unexpected shell behavior
- Remove unauthorized modifications during incident response

## 6. Operational Impact
If successful, T1546.004 can:
- Provide low-noise, user-context persistence
- Execute malicious code repeatedly during normal workflows
- Evade detection mechanisms focused on boot or logon events
- Complicate remediation if multiple shells are affected

## 7. Analyst Notes
Shell configuration abuse is common in environments with extensive CLI usage, such as developer workstations and servers. Analysts should examine **both user-level and system-level shell configuration files**, as attackers may leverage whichever offers the least resistance and highest execution frequency.
