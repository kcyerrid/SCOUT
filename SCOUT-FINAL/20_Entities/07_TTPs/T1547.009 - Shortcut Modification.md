# T1547.009 – Shortcut Modification

## 1. Technique Overview
**Shortcut Modification (T1547.009)** is a sub-technique of **Boot or Logon Autostart Execution (T1547)** in MITRE ATT&CK v18. Adversaries modify **shortcut files** (such as Windows `.lnk` files or macOS application aliases) so that malicious commands or executables are launched when users attempt to open legitimate applications.

This technique relies heavily on user interaction but provides a stealthy persistence mechanism by hijacking trusted application launch workflows.

## 2. Adversary Objectives
Adversaries use this technique to:
- Gain repeated execution through normal user behavior
- Hide malicious execution behind trusted application icons
- Avoid creating new startup artifacts
- Maintain persistence without elevated privileges

## 3. Common Abuse Patterns
- Modifying `.lnk` target paths to prepend malicious commands
- Appending malicious command-line arguments to shortcuts
- Replacing shortcut targets with attacker-controlled binaries
- Placing modified shortcuts on desktops or taskbars
- Masquerading shortcuts with legitimate names and icons

## 4. Detection Considerations
Detection relies on **file integrity and execution monitoring**, including:
- Monitoring changes to shortcut files in common locations
- Detecting unusual command-line arguments from shortcut execution
- Alerting on shortcuts launching unexpected binaries or scripts
- Comparing shortcut targets against known-good baselines
- Correlating shortcut execution with suspicious child processes

## 5. Defensive Mitigations
- Implement file integrity monitoring for shortcut locations
- Restrict user permissions to modify shared shortcuts
- Use application allowlisting to prevent execution of unauthorized binaries
- Educate users on unexpected application behavior
- Regularly audit desktop and taskbar shortcut configurations

## 6. Operational Impact
If successful, T1547.009 can:
- Enable persistence tied directly to user activity
- Evade traditional startup detection mechanisms
- Facilitate execution of additional malware
- Increase dwell time through low-noise execution

## 7. Analyst Notes
Shortcut modification is deceptively simple but effective, particularly in environments with heavy reliance on desktop shortcuts. During investigations, analysts should inspect shortcut metadata and command-line targets when malware execution recurs only after user interaction.
