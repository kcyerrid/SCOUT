## 1. Summary
Password Managers (T1555.005) covers adversary attempts to obtain credentials stored in third-party password managers by targeting encrypted vault files on disk and/or extracting decrypted credentials or the master password from process memory after the vault is unlocked.

## 2. Technical Overview
Adversaries typically pursue one (or both) of these paths:
- **Vault/file acquisition:** Steal or copy password manager database/vault files (e.g., KeePass `.kdbx`, 1Password vault artifacts, other vendor-specific stores) for offline access attempts.
- **Decrypted-in-memory access:** After a user unlocks the vault, credentials may exist in memory in a usable form; adversaries may read process memory, abuse debugging interfaces, or leverage credential-access exploitation paths to recover plaintext secrets or the master password.

Common defender-relevant behaviors:
- Unexpected processes **reading vault files** or staging them for exfiltration.
- Non-password-manager processes **opening/reading password manager process memory** or loading into the same session context.
- Post-compromise activity chaining: discovery → vault location search → file copy/stage → exfiltration.

## 3. Subtechnique Considerations
As a subtechnique of **Credentials from Password Stores (T1555)**, Password Managers differs from OS-native stores (e.g., Keychain/Windows Credential Manager) by emphasizing:
- **Third-party vault formats** and portability (vault files copied off-host).
- **User unlock dependency**: decrypted credentials often become accessible only after interactive unlock (higher correlation value with user session events).
- **Cross-platform coverage** (Linux/Windows/macOS) and varied telemetry quality depending on EDR coverage and application visibility.

## 5. Detection Guidance
High-signal detection focuses on **(a) vault file access** and **(b) password manager process access**.

Recommended analytics (defender-oriented):
1. **Vault file access by unusual processes**
   - Detect non-password-manager processes reading common vault file extensions/paths.
   - Prioritize reads followed by compression, encryption, or network egress within a short window.
2. **Process access / memory access into password manager**
   - Alert on suspicious handle opens, memory reads, injection attempts, or debugger attachments to password manager processes.
   - Correlate with privilege changes (UAC bypass attempts, new admin tokens) and credential-access tooling presence.
3. **Command-line/interactive hunting patterns**
   - Unusual CLI usage referencing vault artifacts, export functions, or config enumeration.
   - Rapid access across many endpoints/users (suggests campaign-scale credential harvesting).
4. **Exfiltration staging**
   - Vault file copied to temp/user-writable locations, then archived or uploaded.

### 5.1. Data Source Notes
Telemetry that materially improves fidelity:
- **Endpoint process telemetry:** process creation, parent/child chains, code injection, handle opens, memory read indicators.
- **File telemetry:** file open/read events for vault extensions and known vendor directories.
- **User session context:** interactive logon/unlock timing; correlate suspicious access shortly after unlock.
- **Network telemetry:** new outbound connections after vault access, especially to rare destinations or via unapproved tools.

## 6. Response Guidance
1. **Containment**
   - Isolate impacted hosts (especially those with confirmed vault file access or process memory access).
   - Disable/rotate credentials associated with affected users; prioritize privileged identities.
2. **Credential hygiene actions**
   - Force password manager vault re-key/master password reset where feasible.
   - Rotate high-impact secrets (VPN, IdP, admin, API keys) first.
3. **Forensics**
   - Identify which vault artifacts were accessed/copied and by which process lineage.
   - Check for evidence of vault export operations and exfiltration paths.
4. **Hardening**
   - Enforce short vault auto-lock timeouts and restrict export features where supported.
   - Strengthen EDR protections around password manager processes and sensitive file locations.

## 8. SOC Relevance
- **High impact**: credential compromise enables privilege escalation, lateral movement, and persistence.
- **High signal**: password manager process access and vault file reads are uncommon for most enterprise software.
- **Practical triage**: strong pivot points exist (vault filename/path, process access patterns, timing after unlock).

## 12. Mitigations
- **M1027 - Password Policies**: enforce strong master passwords (and align with modern digital identity guidance where applicable).
- **M1054 - Software Configuration**: shorten vault auto-lock timeouts; restrict exports where possible.
- **M1051 - Update Software**: keep password managers and related components patched to reduce exploit paths.
- **M1018 - User Account Management**: minimize exposure of privileged accounts and reduce unnecessary access.
- **M1017 - User Training**: train users on secure password manager usage and phishing awareness.
