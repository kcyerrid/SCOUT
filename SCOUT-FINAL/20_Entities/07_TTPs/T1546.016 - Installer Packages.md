# T1546.016 – Installer Packages

## 1. Technique Overview
**Installer Packages (T1546.016)** is a sub-technique of **Event Triggered Execution (T1546)** in **MITRE ATT&CK v18**. Adversaries abuse **software installer and package management mechanisms** to execute malicious code as part of legitimate installation, upgrade, or repair workflows. Because installers commonly run with elevated privileges and are trusted by users and administrators, this technique provides a stealthy and high-impact execution vector.

This technique is observed across traditional desktop platforms as well as server and enterprise environments where automated package management is common.

## 2. Adversary Objectives
Adversaries use installer package abuse to:
- Execute malicious code with elevated privileges
- Establish persistence during legitimate software installation events
- Blend malicious activity into trusted administrative workflows
- Evade detection by leveraging expected installer behavior

## 3. Common Abuse Patterns
- Embedding malicious scripts or binaries in installer packages
- Abusing pre-install or post-install scripts/hooks
- Modifying legitimate installer packages or update bundles
- Leveraging package managers to deploy malicious payloads
- Triggering execution during repair or upgrade operations

## 4. Detection Considerations
Detection relies on **installer execution and integrity monitoring**, including:
- Monitoring execution of installer processes and scripts
- Alerting on unexpected network or file activity during installations
- Validating installer package signatures and checksums
- Correlating installer events with anomalous process execution
- Auditing package manager logs for unauthorized modifications

## 5. Defensive Mitigations
- Enforce signature verification for installer packages
- Restrict who can install or modify software
- Monitor installer execution with endpoint detection tooling
- Use trusted repositories for package management
- Review installer logs during incident response

## 6. Operational Impact
If successful, T1546.016 can:
- Enable privileged code execution
- Establish persistence during routine administrative activity
- Evade detection due to trusted installer context
- Complicate forensic timelines due to blended execution

## 7. Analyst Notes
Installer package abuse is particularly effective in environments with frequent automated updates or DevOps pipelines. Analysts should review **pre-install and post-install scripts** and validate package provenance when investigating unexplained execution tied to software installation events.
