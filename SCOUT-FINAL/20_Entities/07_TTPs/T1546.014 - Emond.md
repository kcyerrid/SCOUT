# T1546.014 – Emond

## 1. Technique Overview
**Emond (T1546.014)** is a sub-technique of **Event Triggered Execution (T1546)** in **MITRE ATT&CK v18**. Adversaries abuse macOS’s **Event Monitor Daemon (emond)**, a legacy event-handling service, to execute attacker-controlled commands when specific system events occur.

Although emond is deprecated in modern macOS versions, it may still be present or enabled in older or misconfigured environments, making it a viable persistence and privilege escalation mechanism in certain scenarios.

## 2. Adversary Objectives
Adversaries use emond to:
- Achieve event-driven persistence on macOS
- Execute malicious code without direct user interaction
- Blend malicious logic into legitimate event-handling workflows
- Maintain access across reboots or system events

## 3. Common Abuse Patterns
- Creating or modifying emond rules under:
  - `/etc/emond.d/rules/`
- Defining event triggers that execute shell commands or scripts
- Masquerading malicious rules as legitimate system maintenance tasks
- Using emond to execute payloads in response to file, process, or system events
- Combining emond with other persistence mechanisms for redundancy

## 4. Detection Considerations
Detection relies on **configuration and file integrity monitoring**, including:
- Monitoring creation or modification of emond rule files
- Auditing emond configuration directories for unauthorized entries
- Correlating system events with unexpected command execution
- Identifying use of deprecated services on modern macOS systems
- Reviewing process execution chains triggered by emond

## 5. Defensive Mitigations
- Disable emond where it is not required
- Monitor emond configuration directories with integrity controls
- Remove unauthorized emond rules during incident response
- Use endpoint security tooling that detects legacy persistence mechanisms
- Reimage or upgrade systems where emond abuse is detected

## 6. Operational Impact
If successful, T1546.014 can:
- Provide stealthy, condition-based persistence
- Execute malicious code with elevated privileges
- Evade detection focused on modern macOS mechanisms
- Complicate response due to legacy service usage

## 7. Analyst Notes
Emond is rarely used legitimately on modern macOS systems, making its presence a strong anomaly signal. Analysts should treat **any non-default emond configuration as suspicious** and prioritize investigation, especially when operating in mixed-version macOS environments.
