# T1547.004 – Winlogon Helper DLL

## 1. Technique Overview
**Winlogon Helper DLL (T1547.004)** is a sub-technique of **Boot or Logon Autostart Execution (T1547)** in MITRE ATT&CK v18. Adversaries abuse the **Winlogon** process by registering malicious helper DLLs that are automatically loaded during user logon events. These DLLs execute with elevated privileges as part of the Windows authentication workflow.

Because Winlogon is a trusted and critical system component, abuse of this mechanism provides highly reliable persistence and may enable privilege escalation.

## 2. Adversary Objectives
Adversaries use this technique to:
- Achieve persistent execution during user logon
- Execute code within a privileged system process
- Maintain access across reboots and logouts
- Support credential access or secondary payload execution

## 3. Common Abuse Patterns
- Registering malicious DLLs in Winlogon registry keys such as:
  - `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon`
- Modifying values like `Userinit`, `Shell`, or `Notify`
- Masquerading malicious DLLs as legitimate system components
- Combining Winlogon abuse with credential theft or screen capture
- Using the mechanism to load additional malware at logon

## 4. Detection Considerations
Detection requires **registry and process monitoring**, including:
- Monitoring changes to Winlogon-related registry values
- Detecting unexpected DLL loads by `winlogon.exe`
- Alerting on unsigned or anomalous DLLs in system directories
- Correlating Winlogon modifications with suspicious authentication activity
- Reviewing persistence artifacts during incident response

## 5. Defensive Mitigations
- Restrict administrative access to Winlogon registry keys
- Enforce code signing for system DLLs
- Monitor integrity of Winlogon configuration
- Use endpoint detection tools that track DLL load behavior
- Treat unauthorized Winlogon modifications as critical incidents

## 6. Operational Impact
If successful, T1547.004 can:
- Provide stealthy, high-privilege persistence
- Enable execution during every logon event
- Facilitate credential access and lateral movement
- Significantly complicate detection and remediation

## 7. Analyst Notes
Winlogon Helper DLL abuse is rare but extremely powerful. Because it integrates directly into the authentication workflow, defenders should treat any unexpected Winlogon configuration change as a strong indicator of compromise. Remediation often requires offline analysis and full system validation.
