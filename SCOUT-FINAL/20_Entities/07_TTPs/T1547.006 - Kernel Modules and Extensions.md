# T1547.006 – Kernel Modules and Extensions

## 1. Technique Overview
**Kernel Modules and Extensions (T1547.006)** is a sub-technique of **Boot or Logon Autostart Execution (T1547)** in MITRE ATT&CK v18. Adversaries abuse operating system support for **kernel-level modules, drivers, or extensions** to ensure malicious code is loaded automatically during system boot. Because kernel components operate at the highest privilege level, this technique provides extremely powerful and durable persistence.

This technique applies across multiple platforms, including Windows kernel drivers, Linux kernel modules, and macOS kernel extensions (kexts).

## 2. Adversary Objectives
Adversaries use this technique to:
- Achieve persistent execution at system boot
- Operate with kernel-level privileges
- Bypass user-mode security controls
- Hide malicious activity from security tools

## 3. Common Abuse Patterns
- Installing malicious Windows kernel drivers configured to load at boot
- Loading unsigned or malicious Linux kernel modules (`.ko` files)
- Deploying macOS kernel extensions prior to or in environments without strict signing enforcement
- Modifying system configuration to auto-load kernel components
- Using kernel-level persistence to support rootkits or stealth backdoors

## 4. Detection Considerations
Detection is challenging and requires **low-level system visibility**, including:
- Monitoring installation or loading of new kernel drivers or modules
- Detecting unsigned or improperly signed kernel components
- Alerting on kernel module load events outside approved maintenance windows
- Comparing loaded kernel modules against known-good baselines
- Correlating kernel activity with userland anomalies

## 5. Defensive Mitigations
- Enforce kernel module and driver signing requirements
- Enable Secure Boot where supported
- Restrict administrative privileges required to load kernel components
- Monitor kernel module load events and configuration changes
- Reimage systems suspected of kernel-level compromise

## 6. Operational Impact
If successful, T1547.006 can:
- Provide near-undetectable, long-term persistence
- Grant attackers full control over the operating system
- Undermine endpoint detection and response tooling
- Make remediation extremely difficult without full system rebuilds

## 7. Analyst Notes
Kernel-level persistence represents one of the most severe forms of compromise. Once adversaries operate within the kernel, traditional forensic and security tooling may be blind to malicious activity. Organizations should treat suspected abuse of kernel modules or extensions as a **high-severity incident** requiring immediate containment and full system validation.
