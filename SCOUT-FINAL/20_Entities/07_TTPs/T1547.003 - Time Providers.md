# T1547.003 – Time Providers

## 1. Technique Overview
**Time Providers (T1547.003)** is a sub-technique of **Boot or Logon Autostart Execution (T1547)** in MITRE ATT&CK v18. Adversaries abuse Windows **time provider** functionality by registering malicious dynamic-link libraries (DLLs) that are loaded by the Windows Time service (`w32time`). This ensures adversary-controlled code is executed during system startup and periodic time synchronization events.

Because time providers are trusted components used by the operating system, this technique offers stealthy persistence and may execute with elevated privileges.

## 2. Adversary Objectives
Adversaries use this technique to:
- Maintain persistent execution across system reboots
- Execute code in the context of a trusted Windows service
- Evade detection by leveraging obscure, low-visibility mechanisms
- Support follow-on activities such as credential access or lateral movement

## 3. Common Abuse Patterns
- Registering malicious DLLs as time providers via:
  - `HKLM\SYSTEM\CurrentControlSet\Services\W32Time\TimeProviders`
- Modifying existing provider entries to load attacker-controlled DLLs
- Masquerading malicious providers as legitimate time synchronization components
- Leveraging periodic time sync events for repeated code execution
- Combining time provider abuse with other LSA or service-based persistence techniques

## 4. Detection Considerations
Detection is challenging and requires **registry and service-level monitoring**, including:
- Monitoring changes to W32Time TimeProviders registry keys
- Detecting new or unsigned DLLs loaded by the Windows Time service
- Alerting on time provider changes outside approved administrative activity
- Correlating time provider modifications with anomalous service behavior
- Reviewing service startup logs for unexpected module loads

## 5. Defensive Mitigations
- Restrict administrative access to W32Time configuration registry keys
- Monitor integrity of time provider DLLs
- Enforce code signing and allowlisting for system service components
- Audit Windows Time service configurations periodically
- Investigate any unauthorized modification as a high-severity event

## 6. Operational Impact
If successful, T1547.003 can:
- Provide long-term, stealthy persistence
- Enable execution with elevated privileges
- Bypass common persistence detection mechanisms
- Complicate incident response due to low visibility

## 7. Analyst Notes
Time provider abuse is uncommon but highly effective due to its obscurity. Many environments lack monitoring around Windows Time service configuration, making this technique attractive for advanced adversaries. During incident response, defenders should explicitly review **W32Time TimeProviders** entries when other persistence mechanisms are not immediately apparent.
