# T1037.005 – Startup Items

## 1. Technique Overview
**Startup Items (T1037.005)** is a sub-technique of **Boot or Logon Initialization Scripts (T1037)** in **MITRE ATT&CK v18**. This technique refers to the use of **startup item scripts or executable components that are automatically executed during the system boot process** to achieve persistence. Historically used on older macOS systems under paths such as `/Library/StartupItems`, startup items may be abused to place attacker-controlled scripts or executables that run as part of the operating system initialization. :contentReference[oaicite:1]{index=1}

## 2. Adversary Objectives
Adversaries may leverage startup items to:
- Maintain persistence across reboots
- Execute malicious code at the system startup phase
- Blend into legitimate system initialization activities
- Achieve persistence without using more modern or heavily monitored mechanisms

## 3. Common Abuse Patterns
- Placing malicious directories and script files into legacy startup locations (e.g., macOS `/Library/StartupItems`)
- Including configuration files such as `StartupParameters.plist` paired with executable payloads
- Masquerading malicious startup items as legitimate system or application components
- Exploiting deprecated or legacy initialization mechanisms that may be less monitored

## 4. Detection Considerations
Detecting abuse of startup items requires **boot-time configuration and file integrity monitoring**, including:
- Tracking file creation and modification in legacy startup directories
- Monitoring for the presence of unauthorized executables in startup item locations
- Correlating boot events with unexpected process execution
- Alerting on use of deprecated or unusual initialization constructs

## 5. Defensive Mitigations
- Restrict write permissions to startup item and system initialization directories
- Monitor and alert on file creation in known legacy startup locations
- Use endpoint detection solutions with macOS persistence visibility
- Regularly audit boot-time initialization artifacts
- Remove legacy startup item support if no longer required by systems

## 6. Operational Impact
If successful, T1037.005 can:
- Provide persistent execution at each system reboot
- Evade detection mechanisms focused on modern persistence vectors
- Trigger malicious payloads early in system lifecycle
- Increase dwell time on affected systems

## 7. Analyst Notes
Startup items are a **legacy macOS persistence mechanism** and are typically less common on modern systems, having largely been superseded by mechanisms such as launch daemons and launch agents. However, their presence on older or misconfigured systems makes them a viable persistence vector, especially when standard persistence mechanisms are monitored or restricted. :contentReference[oaicite:2]{index=2}
