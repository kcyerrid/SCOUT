# T1136.002 – Domain Account

## 1. Technique Overview
**Domain Account (T1136.002)** is a sub-technique of **Create Account (T1136)** in **MITRE ATT&CK v18**. Adversaries create **new domain user or service accounts** within an Active Directory environment to achieve persistence, escalate privileges, or facilitate lateral movement. Because domain accounts are centrally managed and trusted, malicious accounts can provide broad and durable access if not promptly detected.

This technique typically follows compromise of credentials with sufficient privileges to create or manage domain accounts.

## 2. Adversary Objectives
Adversaries create domain accounts to:
- Maintain long-term access to enterprise environments
- Bypass remediation focused on compromised credentials
- Blend malicious access into legitimate directory activity
- Enable privilege escalation and lateral movement

## 3. Common Abuse Patterns
- Creating new domain user accounts using administrative tools or APIs
- Adding attacker-created accounts to privileged domain groups
- Creating service accounts for scheduled tasks or services
- Using naming conventions that resemble legitimate users or services
- Delegating excessive permissions to newly created accounts

## 4. Detection Considerations
Detection relies on **directory service auditing and identity monitoring**, including:
- Monitoring domain account creation events
- Alerting on new accounts added to privileged groups
- Correlating account creation with anomalous authentication behavior
- Reviewing Active Directory audit logs for unauthorized changes
- Tracking service account creation outside approved workflows

## 5. Defensive Mitigations
- Enforce least privilege for account creation permissions
- Require approval workflows for new domain accounts
- Enable comprehensive auditing for directory changes
- Monitor privileged group membership changes
- Regularly reconcile domain account inventories

## 6. Operational Impact
If successful, T1136.002 can:
- Provide scalable and durable persistence
- Enable broad administrative access
- Facilitate lateral movement across the domain
- Undermine trust in directory governance

## 7. Analyst Notes
Domain account creation is one of the most effective persistence mechanisms in Active Directory environments. During incident response, analysts must enumerate **all recently created accounts**, including service accounts, and verify their legitimacy. Failure to remove attacker-created domain accounts often results in rapid re-compromise.
