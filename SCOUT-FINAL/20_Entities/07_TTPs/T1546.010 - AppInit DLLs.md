# T1546.010 – AppInit DLLs

## 1. Technique Overview
**AppInit DLLs (T1546.010)** is a sub-technique of **Event Triggered Execution (T1546)** in **MITRE ATT&CK v18**. Adversaries abuse the Windows **AppInit DLL** mechanism to force the operating system to load attacker-controlled DLLs into every process that loads `user32.dll`.

Because many Windows applications rely on `user32.dll`, this technique enables broad execution coverage and persistent code execution across numerous processes, often with elevated privileges.

## 2. Adversary Objectives
Adversaries use AppInit DLLs to:
- Achieve widespread execution across user-facing processes
- Maintain persistent access without explicit startup artifacts
- Inject malicious code into trusted applications
- Escalate privileges or intercept sensitive user activity

## 3. Common Abuse Patterns
- Registering malicious DLLs under:
  - `HKLM\Software\Microsoft\Windows NT\CurrentVersion\Windows\AppInit_DLLs`
- Enabling AppInit loading via `LoadAppInit_DLLs`
- Placing DLLs in system or attacker-controlled directories
- Masquerading DLL names as legitimate components
- Using injected code to monitor, manipulate, or hijack application behavior

## 4. Detection Considerations
Detection relies on **registry, module load, and process monitoring**, including:
- Monitoring changes to AppInit-related registry keys
- Detecting unexpected DLL loads into multiple processes
- Correlating widespread DLL injection with anomalous behavior
- Auditing systems for unauthorized AppInit DLL registrations
- Reviewing process module lists for suspicious libraries

## 5. Defensive Mitigations
- Monitor and alert on AppInit DLL registry modifications
- Enforce code signing and DLL load restrictions
- Restrict administrative privileges required to configure AppInit DLLs
- Use endpoint security tools capable of detecting DLL injection
- Remove unauthorized AppInit DLLs during incident response

## 6. Operational Impact
If successful, T1546.010 can:
- Provide pervasive, system-wide persistence
- Enable stealthy execution within trusted processes
- Complicate detection and forensic analysis
- Facilitate credential theft or user activity monitoring

## 7. Analyst Notes
Although modern Windows versions limit AppInit DLL usage through security controls, misconfigurations and legacy systems may still allow abuse. Analysts should treat any non-default AppInit DLL presence as highly suspicious and prioritize immediate investigation.
