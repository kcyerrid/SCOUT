# T1556.002 – Password Filter DLL

## 1. Technique Overview
**Password Filter DLL (T1556.002)** is a sub-technique of [[20_Entities/07_TTPs/T1556 - Modify Authentication Process|T1556]] in **MITRE ATT&CK v18**. Adversaries abuse **Windows password filter DLLs**, which are loaded by the Local Security Authority Subsystem Service (LSASS) on domain controllers and certain Windows systems, to inspect or manipulate passwords during authentication and password change operations.

Because password filter DLLs execute within LSASS and are invoked during every relevant authentication event, this technique enables **high-fidelity credential capture** and durable persistence at the identity layer.

## 2. Adversary Objectives
Adversaries use malicious password filter DLLs to:
- Capture plaintext passwords during authentication or password changes
- Bypass or weaken password policy enforcement
- Maintain persistent access to credentials despite user behavior
- Operate stealthily within trusted authentication processes

## 3. Common Abuse Patterns
- Installing a malicious password filter DLL on a domain controller
- Registering the DLL via the `Notification Packages` registry value
- Masquerading the DLL as a legitimate security or policy component
- Logging or exfiltrating captured credentials
- Combining with other identity attacks to expand control

## 4. Detection Considerations
Detection relies on **identity-focused and low-level system monitoring**, including:
- Monitoring changes to password filter registry configurations
- Auditing LSASS module loads for unauthorized DLLs
- Correlating authentication activity with unexpected network or file writes
- Applying file integrity monitoring to authentication-related DLLs
- Reviewing domain controller change logs and reboot events

## 5. Defensive Mitigations
- Enforce strict controls on installing or modifying password filter DLLs
- Monitor and alert on changes to LSASS-loaded modules
- Restrict administrative access to domain controllers
- Require code signing and validation for authentication components
- Rebuild affected systems if unauthorized password filters are detected

## 6. Operational Impact
If successful, T1556.002 can:
- Enable large-scale plaintext credential harvesting
- Undermine trust in enterprise authentication systems
- Persist beyond password resets and account remediation
- Require enterprise-wide credential hygiene and incident response

## 7. Analyst Notes
Malicious password filter DLLs represent a **direct compromise of the authentication pipeline**. Analysts should treat their discovery as an indicator of **advanced and high-impact intrusion**, prioritizing immediate containment of domain controllers and rapid credential rotation.
