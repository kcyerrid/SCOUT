# T1556.007 – Hybrid Identity

## 1. Technique Overview
**Hybrid Identity (T1556.007)** is a sub-technique of [[20_Entities/07_TTPs/T1556 - Modify Authentication Process|T1556]] in **MITRE ATT&CK v18**. Adversaries exploit **hybrid identity architectures**—where on-premises identity systems (such as Active Directory) are synchronized with cloud identity providers—to bypass authentication controls, persist across environments, or weaken enforcement such as MFA.

Because hybrid identity systems bridge trust between environments, abuse at one layer can propagate to the other, enabling durable and stealthy access.

## 2. Adversary Objectives
Adversaries use hybrid identity abuse to:
- Persist across on-premises and cloud identity boundaries
- Bypass or downgrade authentication controls in one environment via the other
- Maintain access despite remediation efforts in a single identity plane
- Exploit trust relationships to escalate privileges or expand access

## 3. Common Abuse Patterns
- Manipulating identity synchronization mechanisms (e.g., directory sync services)
- Abusing federation or trust configurations between identity providers
- Downgrading authentication requirements on one side of the hybrid boundary
- Persisting through synchronized service accounts or privileged identities
- Leveraging compromised on-prem accounts to access cloud resources, or vice versa

## 4. Detection Considerations
Detection requires **cross-environment identity visibility**, including:
- Monitoring changes to identity synchronization configurations
- Auditing privileged account activity across on-prem and cloud directories
- Correlating authentication events between environments for anomalies
- Detecting MFA enforcement inconsistencies across identity planes
- Reviewing logs from identity sync and federation services

## 5. Defensive Mitigations
- Apply strict controls and monitoring to identity synchronization services
- Enforce consistent authentication policies across on-prem and cloud identities
- Require MFA for administrative actions in both identity environments
- Regularly audit trust and federation configurations
- Limit privileges of synchronized service accounts

## 6. Operational Impact
If successful, T1556.007 can:
- Enable long-term persistence across identity environments
- Undermine centralized identity and access management controls
- Complicate incident response due to cross-domain trust
- Expand adversary reach across cloud and on-prem assets

## 7. Analyst Notes
Hybrid identity abuse is often subtle and manifests as **policy drift or trust misuse** rather than overt compromise. Analysts should investigate identity incidents holistically, validating **both sides of the hybrid boundary**, as remediation in only one environment is frequently insufficient.
