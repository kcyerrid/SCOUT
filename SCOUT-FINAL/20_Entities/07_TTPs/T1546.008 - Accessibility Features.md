# T1546.008 – Accessibility Features

## 1. Technique Overview
**Accessibility Features (T1546.008)** is a sub-technique of **Event Triggered Execution (T1546)** in **MITRE ATT&CK v18**. Adversaries abuse Windows **accessibility executables** (such as Sticky Keys, Utility Manager, or On-Screen Keyboard) that can be launched from the logon screen to execute attacker-controlled programs **before user authentication**.

By replacing or redirecting these binaries, attackers can gain execution in a privileged context without valid credentials.

## 2. Adversary Objectives
Adversaries use this technique to:
- Achieve execution prior to user authentication
- Bypass normal logon restrictions
- Escalate privileges to SYSTEM
- Establish persistence on locked systems

## 3. Common Abuse Patterns
- Replacing accessibility executables such as:
  - `sethc.exe`
  - `utilman.exe`
  - `osk.exe`
- Modifying registry entries to redirect accessibility feature execution
- Triggering execution via keyboard shortcuts at the logon screen
- Masquerading malicious binaries as legitimate system files
- Restoring original binaries post-execution to reduce detection

## 4. Detection Considerations
Detection relies on **file integrity and behavior monitoring**, including:
- Monitoring changes to accessibility executable files
- Detecting execution of accessibility binaries spawning command shells
- Correlating pre-logon execution events with suspicious processes
- Auditing registry modifications tied to accessibility features
- Baseline comparison of system binary hashes

## 5. Defensive Mitigations
- Enforce file integrity protections on system binaries
- Monitor and alert on modifications to accessibility executables
- Use endpoint security tools capable of detecting pre-logon abuse
- Restrict physical access to systems
- Reimage systems where accessibility feature abuse is detected

## 6. Operational Impact
If successful, T1546.008 can:
- Provide SYSTEM-level execution without credentials
- Bypass authentication controls entirely
- Enable persistent privileged access
- Undermine trust in endpoint security controls

## 7. Analyst Notes
Accessibility feature abuse is a well-known but still effective technique, particularly in environments lacking strict file integrity controls. Analysts should always verify **hashes of accessibility binaries** when investigating privilege escalation or pre-logon execution events.
