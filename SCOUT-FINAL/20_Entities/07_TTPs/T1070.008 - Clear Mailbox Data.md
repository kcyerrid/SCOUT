# Indicator Removal on Host: Clear Mailbox Data (T1070.008)

## 1. Summary
Clear Mailbox Data describes adversaries **deleting or purging email messages, folders, or entire mailboxes** to remove evidence of malicious activity. This technique is commonly observed in business email compromise (BEC), cloud account takeover, and espionage campaigns targeting email platforms.

Attackers use this technique to:
- Conceal phishing or malicious correspondence
- Remove evidence of unauthorized access
- Obscure command-and-control or exfiltration via email
- Delay detection and incident response

---

## 2. Technical Overview
Modern email platforms store extensive metadata and message content. Adversaries impair these artifacts by:

- Deleting emails from inbox, sent, or deleted items folders
- Purging mailboxes or specific message threads
- Removing audit-relevant folders or labels
- Using API-based access to delete mailbox content at scale

Common platforms affected:
- Microsoft Exchange / Microsoft 365
- Google Workspace
- On-premises mail servers

Indicators include:
- Sudden deletion of large volumes of email
- Removal of specific message threads tied to intrusion activity
- Audit log entries showing mailbox purge actions
- Mailbox changes without corresponding user interaction

---

## 3. Subtechnique Considerations
Key considerations for T1070.008:
- Often paired with **Email Collection (T1114)**
- Common in **cloud and SaaS intrusions**
- Requires mailbox or tenant-level permissions
- Reduces visibility into phishing and BEC operations

Mailbox data removal is frequently **targeted and selective**, not indiscriminate.

---

## 4. Procedure Examples
Representative adversary behaviors include:
- Deleting phishing-related emails after account compromise
- Purging inboxes to hide attacker correspondence
- Removing sent messages to conceal outbound activity
- Using APIs to bulk-delete mailbox content

*(Examples are representative and intentionally non-operational.)*

---

## 5. Detection Guidance
Detection should focus on **mailbox integrity and access patterns**:
- Alert on bulk mailbox deletion events
- Detect mailbox purge actions via admin or API access
- Monitor unusual deletion timing or volume
- Correlate mailbox changes with suspicious identity activity

### Data Source Notes
- **Email server logs**: Primary visibility
- **Cloud audit logs**: Track API-based mailbox operations
- **Identity provider logs**: Attribute mailbox access
- **EDR telemetry**: Correlate with endpoint activity when applicable

Common false positives:
- User cleanup actions
- Automated retention or compliance policies

Tuning guidance:
- Baseline typical deletion behavior per user role
- Elevate alerts for admin-initiated or API-driven deletions

---

## 6. Response Guidance
When suspected:
1. Preserve remaining mailbox data immediately
2. Review audit logs for deletion actions
3. Identify affected users and message scope
4. Recover deleted data where possible
5. Investigate related identity compromise

## 8. SOC Relevance
T1070.008 is highly relevant in:
- Business Email Compromise (BEC) investigations
- Cloud and SaaS account takeovers
- Espionage operations involving email access

Mailbox data loss often explains **missing phishing evidence**.

Commonly used by:
- Financially motivated BEC actors
- Cloud-focused APT groups
- Intrusion sets targeting executive email accounts

---

## 10. Campaign Usage
Observed in:
- BEC campaigns
- Cloud account takeover operations
- Espionage targeting email communications

---

## 11. Malware Usage
Associated with:
- Email-focused malware
- Automation scripts abusing mail APIs
- Post-exploitation tooling for cloud platforms

---

## 12. Mitigations
Recommended mitigations:
- Enforce MFA for email and admin access
- Enable mailbox auditing and retention
- Restrict API-based mailbox access
- Monitor and alert on bulk deletion actions

---

## 13. Testing & Validation
Validation approaches:
- Simulate benign mailbox deletions in test tenants
- Validate alerts on bulk deletion events
- Test SOC workflows for mailbox recovery
- Ensure audit logs capture mailbox operations
