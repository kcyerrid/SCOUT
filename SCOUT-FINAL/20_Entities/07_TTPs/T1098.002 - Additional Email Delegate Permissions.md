# T1098.002 – Account Privileges

## 1. Technique Overview
**Account Privileges (T1098.002)** is a MITRE ATT&CK sub-technique in which adversaries **modify the privileges of existing accounts** to gain elevated access or ensure persistence. Rather than creating new accounts, attackers adjust roles, group memberships, or permissions, allowing them to blend malicious activity with legitimate administrative behavior.

This technique is commonly used after initial access and credential compromise.

## 2. Adversary Objectives
Adversaries employ this technique to:
- Escalate privileges to administrative or root-level access
- Maintain long-term persistence without creating new accounts
- Enable lateral movement across systems
- Avoid detection by abusing trusted identities

## 3. Common Abuse Patterns
- Adding a compromised user to privileged groups (e.g., Domain Admins, sudoers)
- Assigning elevated IAM roles in cloud environments
- Modifying local group memberships on endpoints
- Granting excessive permissions to service accounts
- Altering role assignments to bypass access controls

## 4. Detection Considerations
Effective detection depends on **identity and access monitoring**, including:
- Alerts on changes to privileged group memberships
- Monitoring role or permission modifications
- Correlating privilege changes with unusual login activity
- Detecting privilege escalation outside approved change windows
- Reviewing cloud audit logs for IAM role updates

## 5. Defensive Mitigations
- Enforce **least privilege** principles across all environments
- Require multi-factor authentication for privileged accounts
- Implement approval workflows for privilege changes
- Monitor and audit privileged group membership regularly
- Use just-in-time (JIT) access models where possible

## 6. Operational Impact
If successful, T1098.002 can:
- Provide attackers with broad control over environments
- Undermine access control models
- Enable rapid lateral movement and data compromise
- Complicate incident response and containment

## 7. Analyst Notes
Account privilege modification is a high-impact technique because it leverages trusted administrative actions. Organizations with weak privilege auditing may never detect this behavior until secondary impacts, such as ransomware deployment or data exfiltration, occur.
