# T1037.003 – Network Logon Script

## 1. Technique Overview
**Network Logon Script (T1037.003)** is a sub-technique of **Boot or Logon Initialization Scripts (T1037)** in **MITRE ATT&CK v18**. Adversaries abuse **logon scripts hosted on network shares**, commonly referenced by Active Directory user or group policies, to execute malicious commands whenever users authenticate to the domain.

Because these scripts are centrally stored and implicitly trusted, compromise can result in **widespread and repeated execution** across multiple systems.

## 2. Adversary Objectives
Adversaries use network logon scripts to:
- Establish scalable persistence across many users and hosts
- Execute payloads automatically at authentication
- Leverage trusted domain infrastructure
- Regain execution after system restarts or partial remediation

## 3. Common Abuse Patterns
- Modifying existing logon scripts on shared locations (e.g., `SYSVOL`)
- Replacing legitimate scripts with attacker-controlled versions
- Appending malicious commands to batch, PowerShell, or VBScript files
- Hosting scripts on attacker-controlled network shares
- Assigning malicious scripts to high-privilege users or groups

## 4. Detection Considerations
Detection relies on **directory, file share, and script monitoring**, including:
- Monitoring changes to scripts stored in `SYSVOL` or other shared locations
- Auditing Group Policy Objects that reference network scripts
- Detecting script execution during logon events
- Correlating authentication activity with unexpected process launches
- Monitoring access patterns to script-hosting shares

## 5. Defensive Mitigations
- Restrict write access to network logon script locations
- Enable auditing on `SYSVOL` and other script shares
- Monitor and alert on GPO modifications
- Enforce script signing and execution policies
- Regularly review logon scripts for unauthorized changes

## 6. Operational Impact
If successful, T1037.003 can:
- Provide durable and scalable persistence
- Affect large numbers of users and systems
- Enable rapid propagation of malicious activity
- Complicate remediation due to centralized infrastructure

## 7. Analyst Notes
Network logon script abuse is particularly dangerous in mature Active Directory environments because it allows attackers to **scale persistence rapidly**. Incident response must include a full review of shared script repositories and GPO references, not just endpoint-level artifacts.
