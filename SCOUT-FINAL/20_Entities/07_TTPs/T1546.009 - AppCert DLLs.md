# T1546.009 – AppCert DLLs

## 1. Technique Overview
**AppCert DLLs (T1546.009)** is a sub-technique of **Event Triggered Execution (T1546)** in **MITRE ATT&CK v18**. Adversaries abuse the Windows **Application Certification DLL** mechanism to force the operating system to load attacker-controlled DLLs **every time a process is created**.

Because AppCert DLLs are loaded globally and early in process creation, this technique provides powerful, system-wide execution and is commonly associated with high-privilege persistence and credential theft activity.

## 2. Adversary Objectives
Adversaries use AppCert DLLs to:
- Execute malicious code during every process creation event
- Achieve pervasive persistence across the system
- Monitor or tamper with process execution
- Escalate privileges or harvest credentials

## 3. Common Abuse Patterns
- Registering malicious DLLs under:
  - `HKLM\System\CurrentControlSet\Control\Session Manager\AppCertDLLs`
- Placing DLLs in system or attacker-controlled directories
- Using AppCert DLLs to inject into newly created processes
- Masquerading DLL names as legitimate system components
- Leveraging execution context to hook sensitive processes

## 4. Detection Considerations
Detection relies on **registry, DLL load, and process creation telemetry**, including:
- Monitoring changes to the AppCertDLLs registry key
- Detecting unexpected DLL loads across many processes
- Correlating widespread DLL loading with abnormal behavior
- Auditing systems for unauthorized AppCert DLL registrations
- Reviewing process creation chains for injected modules

## 5. Defensive Mitigations
- Monitor and alert on modifications to AppCertDLLs registry keys
- Enforce code signing and DLL load protections
- Restrict administrative privileges required to register AppCert DLLs
- Use endpoint security solutions capable of detecting DLL injection
- Remove unauthorized AppCert DLLs during incident response

## 6. Operational Impact
If successful, T1546.009 can:
- Provide system-wide, high-privilege persistence
- Enable execution across virtually all processes
- Severely complicate detection and remediation
- Facilitate credential access and process manipulation

## 7. Analyst Notes
AppCert DLL abuse is rare but extremely impactful due to its **global execution scope**. Analysts should treat any presence of non-default AppCert DLLs as highly suspicious and prioritize immediate investigation and remediation.
