# T1574.005 – Executable Installer File Permissions Weakness

## 1. Technique Overview
**Executable Installer File Permissions Weakness (T1574.005)** is a sub-technique of **Hijack Execution Flow (T1574)** in **MITRE ATT&CK v18**. Adversaries abuse **improperly secured installer executables or update mechanisms** by modifying or replacing installer files that are later executed with elevated privileges. When the installer or updater runs, the attacker-controlled code executes instead of the legitimate program.

This technique leverages trusted installation workflows and is particularly effective where software update processes run automatically or under administrative contexts.

## 2. Adversary Objectives
Adversaries use this technique to:
- Achieve execution with elevated privileges
- Establish persistence via recurring installer or update execution
- Blend malicious activity into legitimate software maintenance workflows
- Escalate privileges without exploiting software vulnerabilities

## 3. Common Abuse Patterns
- Replacing installer executables located in user-writable directories
- Modifying update binaries used by scheduled or automatic update tasks
- Targeting installers executed by services or system management tools
- Masquerading malicious installers as legitimate update components
- Leveraging predictable installer execution timing for reliability

## 4. Detection Considerations
Detection relies on **file integrity and execution monitoring**, including:
- Monitoring write access to installer and updater directories
- Alerting on modifications to installer executables
- Correlating installer execution with unexpected child processes
- Validating installer signatures prior to execution
- Comparing installer hashes against known-good versions

## 5. Defensive Mitigations
- Enforce strict file permissions on installer and updater files
- Ensure installers are stored in protected, non-user-writable locations
- Require digital signature validation for installers and updates
- Monitor installer execution behavior with endpoint detection tooling
- Audit software update mechanisms for insecure configurations

## 6. Operational Impact
If successful, T1574.005 can:
- Enable privileged execution without exploit development
- Provide stealthy persistence tied to legitimate update activity
- Evade detection due to trusted installer context
- Complicate forensic timelines due to blended execution

## 7. Analyst Notes
Installer permission weaknesses are often overlooked during security reviews. Analysts should inventory **all software update and installation mechanisms**, verify file permissions, and confirm that only trusted processes can modify installer executables—especially for software that runs installers automatically or with elevated privileges.
