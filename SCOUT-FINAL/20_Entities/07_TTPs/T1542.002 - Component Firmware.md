# Pre-OS Boot: Component Firmware (T1542.002)

## 1. Summary
Component Firmware describes adversaries **modifying firmware on individual hardware components**, such as network interface cards (NICs), hard drives, GPUs, or peripheral controllers, to gain stealthy persistence and pre-operating-system execution. This technique enables attackers to operate below the visibility of the host OS and many security controls.

Adversaries use this technique to:
- Establish durable persistence independent of system firmware
- Execute malicious code before or alongside system boot
- Evade OS-level security monitoring
- Survive OS reinstallation and disk replacement

---

## 2. Technical Overview
Modern hardware components often contain embedded firmware that executes independently of the host OS. Adversaries may target:
- Network interface cards (NIC firmware)
- Storage device firmware (HDDs, SSDs)
- Baseboard management controllers (BMCs)
- GPUs or other peripheral devices
- USB or Thunderbolt device firmware

Common techniques include:
- Flashing modified firmware images
- Abusing vendor firmware update mechanisms
- Exploiting vulnerabilities in firmware flashing utilities
- Leveraging compromised supply chains

Indicators include:
- Unexpected firmware version changes on components
- Anomalous device behavior prior to OS boot
- Network traffic originating before OS initialization
- Persistence that survives system reimaging

---

## 3. Subtechnique Considerations
Key considerations for T1542.002:
- Highly stealthy and difficult to detect
- Often requires specialized knowledge or access
- May coexist with system firmware compromise
- Detection typically requires hardware-level tooling

Component firmware compromise operates **outside traditional system trust boundaries**.

---

## 4. Procedure Examples
Representative adversary behaviors include:
- Modifying NIC firmware to intercept or inject traffic
- Implanting malicious logic in storage controller firmware
- Persisting payloads within peripheral firmware
- Leveraging firmware implants for command-and-control

*(Examples are representative and intentionally non-operational.)*

---

## 5. Detection Guidance
Detection should emphasize **hardware integrity and behavioral anomalies**:
- Monitor firmware versions and hashes for components
- Detect anomalous pre-OS or low-level device behavior
- Correlate persistence despite OS reinstallation
- Monitor early network activity from compromised devices

### Data Source Notes
- **Firmware monitoring**: Identify unauthorized component firmware changes
- **Hardware telemetry**: Observe device-level anomalies
- **Boot logs**: Identify pre-OS execution irregularities

Common false positives:
- Legitimate firmware updates
- Hardware replacement or maintenance

Tuning guidance:
- Maintain inventories and baselines of component firmware
- Alert on unsigned or unexpected firmware changes

---

## 6. Response Guidance
When suspected:
1. Isolate the affected system immediately
2. Identify affected hardware components
3. Reflash firmware using vendor-trusted images
4. Replace compromised hardware if necessary
5. Investigate supply-chain or physical access exposure

## 8. SOC Relevance
T1542.002 is critical because:
- Attacks operate below OS visibility
- Traditional EDR tools may be blind
- Remediation may require hardware replacement

SOC teams must treat **component firmware compromise as a severe incident**.

---

- Highly resourced intrusion groups

Observed in:

## 11. Malware Usage
Associated with:
- Firmware implants
- Hardware rootkits
- Persistent pre-OS malware

---

## 12. Mitigations
Recommended mitigations:
- Restrict firmware update capabilities
- Monitor and audit component firmware versions
- Use hardware-backed attestation mechanisms
- Validate firmware integrity during procurement

---

## 13. Testing & Validation
Validation approaches:
- Inventory component firmware in lab systems
- Test detection of unauthorized firmware changes
- Conduct incident response drills for hardware compromise
- Validate vendor firmware reflash procedures
