# Subvert Trust Controls: Gatekeeper Bypass (T1553.001)

## 1. Summary
Gatekeeper Bypass describes adversaries **circumventing macOS Gatekeeper protections** to execute untrusted or malicious software without user warnings. Gatekeeper enforces application signing, notarization, and quarantine checks; bypassing it allows attackers to run payloads silently or make them appear trustworthy.

Adversaries use this technique to:
- Suppress security prompts and warnings
- Execute unsigned or malicious binaries
- Increase phishing and social-engineering success
- Evade macOS application control mechanisms

---

## 2. Technical Overview
Gatekeeper evaluates applications based on:
- Code signing and notarization status
- Quarantine attributes (extended attributes) applied to downloaded files
- Execution context (GUI, Terminal, installers)

Adversaries bypass Gatekeeper by:
- Removing or modifying quarantine extended attributes
- Executing payloads via trusted interpreters or installers
- Packaging malware in formats that suppress Gatekeeper prompts
- Leveraging user-approved execution paths

Indicators include:
- Executables missing quarantine attributes
- Execution of newly downloaded files without prompts
- Extended attribute modification prior to execution
- Execution chains originating from user-writeable directories

---

## 3. Subtechnique Considerations
Key considerations for T1553.001:
- macOS-only technique
- Frequently paired with **User Execution (T1204)**
- Relies on user trust and delivery method
- Detection depends on visibility into extended attributes

Gatekeeper bypass enables **stealthy initial execution**.

---

## 4. Procedure Examples
Representative adversary behaviors include:
- Removing quarantine attributes from downloaded malware
- Delivering trojanized applications that appear legitimate
- Using scripts or installers that evade Gatekeeper enforcement
- Executing payloads via trusted macOS utilities

*(Examples are representative and intentionally non-operational.)*

---

## 5. Detection Guidance
Detection should focus on **file provenance and execution context**:
- Monitor execution of binaries lacking quarantine attributes
- Detect changes to extended attributes on executables
- Alert on execution from user-writeable directories
- Correlate execution events with recent downloads

### Data Source Notes
- **Unified logs**: Capture Gatekeeper and execution-related events
- **File monitoring**: Track extended attribute changes
- **EDR telemetry**: Observe suspicious execution flows

Common false positives:
- Developer workflows
- Administrative scripts

Tuning guidance:
- Baseline legitimate developer and IT behavior
- Elevate alerts following user-facing delivery vectors

---

## 6. Response Guidance
When suspected:
1. Identify affected binaries and users
2. Restore quarantine attributes or remove malicious files
3. Review user activity leading to execution
4. Hunt for similar Gatekeeper bypass activity
5. Reinforce user awareness of security prompts

## 8. SOC Relevance
T1553.001 is critical because:
- Gatekeeper is a primary macOS security boundary
- Bypasses reduce user awareness of risk
- Attacks blend into normal user execution patterns

SOC teams must monitor **how files are introduced and executed on macOS systems**.

## 12. Mitigations
Recommended mitigations:
- Enforce Gatekeeper and notarization
- Monitor quarantine attribute removal
- Restrict execution from user-writeable directories
- Educate users on macOS security warnings

- Validate SOC workflows for Gatekeeper bypass
- Ensure extended attribute telemetry is collected
