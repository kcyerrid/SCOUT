# T1546.006 – LC_LOAD_DYLIB Addition

## 1. Technique Overview
**LC_LOAD_DYLIB Addition (T1546.006)** is a sub-technique of **Event Triggered Execution (T1546)** in **MITRE ATT&CK v18**. Adversaries abuse the macOS **Mach-O** binary format by inserting an additional `LC_LOAD_DYLIB` load command into an existing executable. When the modified binary runs, the operating system dynamically loads the attacker-controlled library, enabling execution without changing the binary’s primary functionality.

This technique leverages legitimate dynamic linking behavior and often targets trusted or frequently executed applications to achieve stealthy persistence.

## 2. Adversary Objectives
Adversaries use this technique to:
- Achieve execution whenever a targeted application launches
- Inherit the trust and permissions of legitimate binaries
- Maintain persistence without adding obvious startup artifacts
- Evade detection by preserving expected application behavior

## 3. Common Abuse Patterns
- Injecting a new `LC_LOAD_DYLIB` entry into Mach-O headers
- Pointing the load command to a malicious `.dylib` stored in user-writable paths
- Targeting commonly launched applications or background utilities
- Preserving original binary signatures where possible to reduce suspicion
- Combining with library path manipulation to ensure successful loading

## 4. Detection Considerations
Detection relies on **binary integrity and runtime loading visibility**, including:
- Monitoring Mach-O binaries for unexpected load commands
- Detecting execution of applications that load unsigned or unusual `.dylib` files
- Comparing binary hashes and load commands against known-good baselines
- Correlating application launches with dynamic library loads from suspicious paths
- Using endpoint tooling capable of inspecting Mach-O metadata

## 5. Defensive Mitigations
- Enforce code signing and signature validation for executables and libraries
- Monitor and alert on modifications to trusted application binaries
- Restrict write permissions to application directories
- Use endpoint security solutions with macOS binary inspection capabilities
- Reinstall or restore compromised applications from trusted sources

## 6. Operational Impact
If successful, T1546.006 can:
- Provide reliable execution tied to legitimate application launches
- Enable stealthy persistence without traditional autorun mechanisms
- Execute code within trusted application contexts
- Complicate detection due to minimal visible artifacts

## 7. Analyst Notes
LC_LOAD_DYLIB abuse is technically sophisticated and often associated with higher-skill macOS threats. During investigations, analysts should inspect **Mach-O load commands**—not just file presence or signatures—when suspected applications behave anomalously despite appearing legitimate.
