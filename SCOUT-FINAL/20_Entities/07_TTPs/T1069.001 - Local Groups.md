## 1. Summary
Local Groups (T1069.001) covers adversary attempts to enumerate **local system groups** and membership (notably local administrators). This is a high-value precursor to privilege abuse, credential access targeting, and lateral movement decisions.

## 2. Technical Overview
Common goals:
- Identify local admin users and groups to prioritize credential theft, privilege escalation, or lateral movement.
- Determine whether a foothold already has elevated privileges.

Typical execution:
- **Windows**: enumeration of local groups and local administrators membership via native utilities or scripting.
- **Linux**: reading local group membership and privilege context via common binaries and file-backed group databases.
- **macOS**: group enumeration via directory service tooling and native commands.

Defender-relevant characteristics:
- Often executed soon after initial access and repeated during privilege escalation attempts.
- In enterprise attacks, local admin discovery frequently precedes:
  - credential dumping,
  - remote execution,
  - persistence installation,
  - ransomware staging.

## 3. Subtechnique Considerations
This is a sub-technique of [[20_Entities/07_TTPs/TA0007 - Discovery/T1069 - Permission Groups Discovery|T1069]].
Key distinctions vs siblings:
- **Local Groups (T1069.001)** focuses on endpoint-local privilege boundaries.
- **Domain Groups (T1069.002)** and **Cloud Groups (T1069.003)** shift telemetry to directory/control-plane sources and broader privilege scope.

## 5. Detection Guidance
Prioritize **endpoint command/process visibility** and correlate to follow-on privilege abuse indicators.

Recommended analytics:
1. **Windows local group enumeration**
   - Alert on local group listing activity when initiated by:
     - uncommon users for admin actions,
     - suspicious parent processes (macro, script dropper, LOLBin chain),
     - remote sessions (RDP/WinRM/SMB exec context),
     - endpoints not used for administration.
2. **Linux local group enumeration**
   - Detect group membership queries and `/etc/group` parsing when executed from remote shells or suspicious script lineage.
3. **macOS local group enumeration**
   - Detect execution patterns indicative of directory-based group listing; correlate with subsequent privilege checks or persistence actions.

Correlation boosters:
- Local group enumeration followed by:
  - credential access attempts,
  - privilege escalation,
  - remote execution/lateral movement artifacts within a short window.

### 5.1 Data Source Notes
Prioritize:
- **DC0032 Process Creation**: command execution of local group enumeration utilities, shells, and scripts (Windows Security 4688 / EDR process telemetry; auditd execve; macOS EndpointSecurity/unified logs where applicable).

## 6. Response Guidance
1. Identify initiating principal and process lineage (interactive user vs service; remote session vs local).
2. Validate against expected admin behavior:
   - admin workstation allowlists; IT scripts; endpoint management tooling.
3. Scope the discovery:
   - which local groups were queried; whether multiple hosts were enumerated.
4. Hunt follow-ons:
   - privilege escalation indicators, credential access attempts, remote execution, persistence creation.
5. Contain if suspicious:
   - isolate host, reset credentials, revoke tokens/sessions, and remove unauthorized local admin membership changes.

## 12. Mitigations
This technique is generally **not easily mitigated** preventively because it can rely on legitimate OS features.
Defender-focused controls:
- Reduce standing local admin privileges; use just-in-time/admin workflows.
- Monitor and alert on unexpected administrative enumeration activity on user endpoints.
- Harden PowerShell and script execution controls; enforce strong EDR coverage on admin tooling endpoints.

## 13. Testing & Validation
- Validate that your environment captures:
  - Windows process creation for local group enumeration activity,
  - Linux auditd exec events for group enumeration binaries,
  - macOS process execution telemetry for directory group enumeration.
- Recommended test content:
  - Atomic Red Team T1069.001 tests (where available) and benign admin enumeration from IT tooling to tune allowlists.
