# T1574.009 – Path Interception by Unquoted Path

## 1. Technique Overview
**Path Interception by Unquoted Path (T1574.009)** is a sub-technique of **Hijack Execution Flow (T1574)** in **MITRE ATT&CK v18**. Adversaries abuse **unquoted file paths that include spaces**, most commonly in Windows service or scheduled task configurations, to redirect execution to attacker-controlled binaries.

When an executable path is not enclosed in quotation marks, Windows may interpret portions of the path as separate executables and attempt to run them in order, allowing attackers to place a malicious binary at a predictable location.

## 2. Adversary Objectives
Adversaries use unquoted path interception to:
- Execute malicious code in elevated contexts
- Establish persistence through auto-start services or tasks
- Escalate privileges without exploiting software vulnerabilities
- Blend execution into legitimate service startup behavior

## 3. Common Abuse Patterns
- Identifying services or tasks with unquoted paths containing spaces
- Placing malicious executables (e.g., `Program.exe`) in writable directories along the path
- Targeting services that run as SYSTEM or other high-privilege accounts
- Leveraging service restarts or system reboots for repeated execution
- Combining with weak directory permissions for reliable exploitation

## 4. Detection Considerations
Detection relies on **configuration auditing and execution monitoring**, including:
- Auditing services and scheduled tasks for unquoted executable paths
- Monitoring creation of executables named after common path segments
- Detecting service execution from unexpected directories
- Correlating privilege escalation with service start events
- Baseline comparison of service binary locations and permissions

## 5. Defensive Mitigations
- Quote all executable paths in services and scheduled tasks
- Restrict write permissions on directories within executable paths
- Regularly audit Windows services for unquoted paths
- Monitor and alert on service configuration changes
- Apply least-privilege principles to service execution contexts

## 6. Operational Impact
If successful, T1574.009 can:
- Provide reliable, privileged execution
- Enable persistence without modifying common autorun registry keys
- Facilitate privilege escalation on misconfigured systems
- Complicate detection due to legitimate service execution patterns

## 7. Analyst Notes
Unquoted path issues remain common in enterprise environments and represent a high-confidence finding when paired with writable directories. Analysts should prioritize remediation where **unquoted paths and weak permissions intersect**, as this combination offers attackers deterministic execution.
