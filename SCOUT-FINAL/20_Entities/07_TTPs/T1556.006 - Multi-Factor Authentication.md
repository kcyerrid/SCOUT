# T1556.006 – Multi-Factor Authentication

## 1. Technique Overview
**Multi-Factor Authentication (T1556.006)** is a sub-technique of [[20_Entities/07_TTPs/T1556 - Modify Authentication Process|T1556]] in **MITRE ATT&CK v18**. Adversaries modify, weaken, or bypass **MFA enforcement mechanisms** within authentication workflows to gain or maintain access without triggering expected security controls.

Rather than stealing MFA tokens directly, this technique focuses on **tampering with MFA validation logic**, configuration, or integration points.

## 2. Adversary Objectives
Adversaries use MFA modification to:
- Bypass MFA requirements for targeted accounts or systems
- Downgrade authentication strength without alerting defenders
- Maintain persistent access after credential resets
- Undermine enterprise-wide identity security controls

## 3. Common Abuse Patterns
- Modifying authentication configuration to exempt accounts from MFA
- Disabling MFA enforcement at the application or service level
- Tampering with MFA providers or validation components
- Exploiting legacy or fallback authentication paths without MFA
- Abusing synchronization gaps in hybrid identity environments

## 4. Detection Considerations
Detection relies on **identity and policy telemetry**, including:
- Monitoring MFA policy changes and enforcement exceptions
- Auditing authentication flows for unexpected MFA bypasses
- Correlating successful logins with missing MFA challenges
- Reviewing administrative actions affecting identity security controls
- Integrating identity provider logs into centralized monitoring

## 5. Defensive Mitigations
- Enforce strict controls and approval workflows for MFA policy changes
- Monitor and alert on MFA configuration modifications
- Require MFA for administrative changes to identity systems
- Regularly audit MFA enforcement across applications and services
- Remove legacy authentication methods that bypass MFA

## 6. Operational Impact
If successful, T1556.006 can:
- Nullify a primary enterprise security control
- Enable stealthy persistence across password changes
- Facilitate lateral movement and privilege escalation
- Significantly increase overall breach impact

## 7. Analyst Notes
MFA modification is often subtle and may not trigger immediate alerts. Analysts should treat **unexpected authentication success without MFA challenges** as a high-confidence indicator of identity compromise and prioritize validation of MFA enforcement across affected systems.
