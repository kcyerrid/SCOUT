# Domain Accounts (T1078.002)

## 1. Summary
Domain Accounts describes adversary abuse of valid credentials associated with centralized directory services (e.g., Active Directory) to authenticate across multiple systems. This subtechnique is particularly dangerous due to the broad access domain accounts often provide, enabling lateral movement, privilege escalation, and long-term persistence.

Because activity leverages legitimate authentication mechanisms, malicious use frequently blends with normal enterprise behavior.

---

## 2. Technical Overview
Adversaries obtain domain credentials through phishing, credential dumping, password spraying, keylogging, or purchasing access from initial access brokers. Once obtained, credentials are used to authenticate to domain-joined hosts, remote services, or directory-backed applications.

Common technical mechanisms include:
- Kerberos and NTLM authentication
- LDAP queries and directory-backed authorization
- Remote access via SMB, RDP, WinRM, VPNs, and web applications

Artifacts include successful authentication events, ticket issuance, directory access logs, and network connections between hosts.

---

## 3. Subtechnique Considerations
T1078.002 focuses on **directory-managed identities**, distinguishing it from:
- Default Accounts
- Local Accounts
- Cloud Accounts

Risk increases significantly when:
- Privileged domain accounts are compromised
- Service accounts have excessive permissions
- Password reuse or weak policies exist

---

## 4. Procedure Examples
Observed adversary procedures include:
- Authenticating to multiple hosts using a single compromised domain user
- Using service account credentials for lateral movement
- Accessing domain controllers or administrative shares

Analysts may observe rapid authentication success across disparate systems without corresponding logon failures.

---

## 5. Detection Guidance
Detection should prioritize identity and authentication analytics:
- Unusual domain logons from new hosts or locations
- Abnormal Kerberos ticket usage or lifetimes
- Service account authentication outside expected schedules
- Lateral authentication patterns inconsistent with role

Correlation between authentication logs and endpoint/network telemetry is essential.

### Data Source Notes
- **Authentication Logs:** High-fidelity when enriched with device and location context
- **Directory Service Logs:** Critical for detecting privilege misuse and enumeration
- **Network Traffic:** Useful for identifying lateral movement paths

---

## 6. Response Guidance
When Domain Account abuse is suspected:
- Immediately validate account owner and intent
- Reset credentials and revoke active sessions
- Review group memberships and delegated privileges
- Hunt for follow-on activity (lateral movement, persistence)

Preserve directory, authentication, and endpoint logs for investigation.

## 8. SOC Relevance
Domain Account abuse is one of the most common precursors to enterprise-wide compromise and ransomware deployment. Detection maturity varies by organization, but identity-focused monitoring provides high defensive ROI.

---

## 9. Threat Actor Usage
This subtechnique is heavily used by:
- Ransomware affiliates and operators
- Advanced persistent threat groups
- Initial access brokers monetizing domain credentials

Confidence in widespread use is extremely high.

---

## 10. Campaign Usage
Domain Accounts appear in:
- Enterprise ransomware intrusions
- Long-dwell espionage campaigns
- Post-compromise lateral movement phases

## 12. Mitigations
Effective mitigations include:
- Enforcing multi-factor authentication for domain access
- Tiered administrative model and least privilege
- Monitoring service account usage
- Strong password and credential hygiene policies
- Restricting lateral authentication paths

---

## 13. Testing & Validation
Validation approaches include:
- Atomic Red Team tests simulating domain credential misuse
- Purple team exercises focused on lateral authentication
- Controlled testing of anomalous Kerberos usage

Successful validation results in timely detection with low false positives.
