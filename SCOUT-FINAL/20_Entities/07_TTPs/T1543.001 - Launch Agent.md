# T1543.001 – Launch Agent

## 1. Technique Overview
**Launch Agent (T1543.001)** is a sub-technique of **Create or Modify System Process (T1543)** in **MITRE ATT&CK v18**. Adversaries abuse **launchd Launch Agents** (property list `.plist` files) to establish persistence by causing attacker-controlled programs to execute **when a user logs in** or based on other launchd conditions. Launch Agents typically run in the **user context**, but they can be paired with additional actions to support privilege escalation. :contentReference[oaicite:2]{index=2}

## 2. Adversary Objectives
Adversaries use Launch Agents to:
- Maintain persistence across user logins
- Blend persistence into a legitimate macOS service management framework
- Trigger execution via trusted launchd behavior
- Reduce visibility compared to more obvious startup artifacts

## 3. Common Abuse Patterns
- Creating `.plist` files in:
  - `/Library/LaunchAgents`
  - `~/Library/LaunchAgents`
- Setting keys such as `RunAtLoad` and/or `KeepAlive` to control execution behavior
- Masquerading the agent label and filename as legitimate software
- Pointing `ProgramArguments` to attacker-controlled binaries or scripts :contentReference[oaicite:3]{index=3}

## 4. Detection Considerations
Detection depends on **file creation/modification** and **launchd execution telemetry**, including:
- New or modified `.plist` files in LaunchAgents directories
- Launch Agents whose `ProgramArguments` reference unusual paths (e.g., user-writable temp locations)
- Correlation of login events with immediate execution of anomalous processes
- Inventory/baselining of known-good Launch Agents vs recent changes :contentReference[oaicite:4]{index=4}

## 5. Defensive Mitigations
- Enforce least privilege and restrict who can write to system LaunchAgents locations
- Monitor LaunchAgents directories with file integrity controls
- Use endpoint tooling that surfaces launchd persistence and agent metadata
- Periodically audit Launch Agents across the fleet against approved software inventories :contentReference[oaicite:5]{index=5}

## 6. Operational Impact
If successful, T1543.001 can:
- Provide durable, low-noise persistence on macOS
- Enable repeated execution without exploiting vulnerabilities
- Increase dwell time by blending into standard macOS management constructs

## 7. Analyst Notes
Launch Agents are a high-yield macOS persistence artifact because they are both common (legitimate software) and easily abused. Response should include: enumerate LaunchAgents, validate provenance of referenced binaries/scripts, and correlate install/modify times with initial access timelines.
