## 1. Summary
Domain Account discovery (T1087.002) covers enumeration of **directory accounts and groups** (e.g., Active Directory or LDAP-backed domains). This is a key precursor to privilege targeting and lateral movement.

## 2. Technical Overview
Typical techniques include:
- Using domain utilities to enumerate users and groups (including high-privilege groups).
- LDAP queries against directory services to retrieve user attributes, group membership, and organizational structure.
- Directory-focused PowerShell cmdlets or recon utilities.

Defender-relevant objectives:
- Identify privileged accounts (domain admins, enterprise admins).
- Identify group membership paths for privilege escalation.
- Map service accounts and delegation relationships.

## 4. Procedure Examples
Observed examples include:
- Built-in domain utilities used to enumerate domain administrators.
- Directory reconnaissance tooling used to enumerate domain users and groups.
- Malware frameworks and post-exploitation toolkits collecting domain account information.

## 5. Detection Guidance
Key detection principle: **directory enumeration is often noisy** when performed at attacker speed/scale.

High-signal patterns:
- **Unusual directory query sources**: non-admin workstations performing LDAP queries to DCs, or endpoints initiating AD reconnaissance tools.
- **Burst queries**: high-volume directory reads (users/groups) in short windows.
- **Recon tools**: presence/execution of known AD recon utilities (including renamed variants) combined with directory query behavior.
- **Privilege-focused filters**: repeated queries for admin groups or “domain admin” membership checks.

Practical analytics:
- Correlate LDAP traffic to DCs with suspicious process execution on the source host (where EDR supports network-to-process binding).
- Alert when a non-IT host queries directory services at scale, especially outside business hours.
- Detect execution of directory recon scripts/tools by hash/signer/behavioral patterns (e.g., querying many object classes/attributes).

### Data Source Notes
Recommended telemetry:
- DC security logs and directory service auditing (where feasible).
- Endpoint process creation + command line + PowerShell logs.
- Network telemetry for LDAP/LDAPS and related directory query traffic.
- Authentication logs to correlate “enumerate → attempt logon” sequences.

## 6. Response Guidance
1. Identify querying principal and source host(s); determine if the activity matches approved directory admin tooling.
2. Measure scope: object count queried, attributes requested, and time window.
3. Hunt for follow-on actions: Kerberos abuse, credential dumping, remote execution, lateral movement.
4. If suspicious: isolate the initiating endpoint, revoke tokens, and review privileged group membership exposure.

## 8. SOC Relevance
- One of the most operationally important discovery behaviors to detect because it frequently precedes privilege escalation paths and credential theft.
- High false-positive potential without baselining IT/admin tooling—use contextual allowlists.

## 12. Mitigations
- Limit who can query sensitive directory attributes; reduce exposure of privileged group membership where possible.
- Restrict directory administration to hardened admin workstations; segment and monitor access to DCs.
- Ensure strong auditing for directory reads and privileged group enumeration.

## 13. Testing & Validation
- Validate detections against known-good admin tools (helpdesk scripts, monitoring products).
- Simulate:
  - High-volume user/group enumeration from a non-admin endpoint
  - Use of directory recon tools (renamed) and confirm behavioral detections still trigger
- Verify alert enrichment includes source process/user and target DC.
