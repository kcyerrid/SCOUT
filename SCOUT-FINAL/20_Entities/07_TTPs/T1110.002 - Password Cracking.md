# T1110.002 - Password Cracking

## 1. Summary
Password Cracking (T1110.002) involves attempting to recover plaintext passwords from obtained credential material (commonly hashes). Unlike online brute force, cracking is typically performed off-network on adversary-controlled infrastructure, then the recovered credentials are used for normal authentication.

## 2. Technical Overview
Common pathways leading into password cracking:
- Credential hashes acquired via credential dumping, directory extraction, or configuration repository access.
- Hash cracking using dictionary, rule-based mutation, or brute-force/rainbow-table approaches.

Defender-relevant implications:
- Cracking itself may not produce enterprise telemetry if performed offsite.
- Detection often relies on **precursor events** (hash access/exfil) and **post-cracking behavior** (new successful logons, lateral movement, privilege access).

## 3. Subtechnique Considerations
- Parent technique: [[20_Entities/07_TTPs/TA0006 - Credential Access/T1110 - Brute Force|T1110]]
- Use T1110.002 when activity centers on **recovering plaintext** from hashes (vs pass-the-hash style usage).
- Pair detections with upstream behaviors that enable cracking (credential access and data staging/exfil).

## 5. Detection Guidance
Detection objective: **detect the acquisition/handling of password hashes and downstream use of newly recovered credentials**.

Practical detections:
- **Hash access & staging indicators** (on endpoints/DCs/network devices):
  - Suspicious access to credential stores and directories containing hash material.
  - Unusual reads/copies of directory database files and related artifacts (where applicable).
- **Tooling/process indicators**:
  - Execution of known hash-cracking binaries/scripts on internal hosts (where observed).
  - High CPU/GPU usage correlated with unsigned/suspicious binaries (contextual, not standalone).
- **Downstream authentication anomalies**:
  - “New” successful logons from accounts shortly after suspected hash exposure.
  - Auth success from unusual hosts/locations for accounts previously dormant or constrained.

Correlation strategy:
- Time-bound linking between: credential store access → suspicious tooling → first-time successful authentications.

### Data Source Notes
This technique page does not present an explicit ATT&CK “Data Sources” list in the technique header; prioritize:
- Endpoint process + file access telemetry (EDR)
- Domain controller security logs (auth patterns and directory access where available)
- Network device configuration access logs (for device-stored hashes/credentials)
- IdP/SaaS sign-in logs (new successful logons after suspected crack window)

## 6. Response Guidance
- If hash exposure is suspected: treat as credential compromise and initiate resets/rotation (prioritize privileged/service accounts).
- Revoke sessions/tokens and re-issue secrets where possible.
- Hunt for lateral movement and privilege escalation following new valid logons.
- Strengthen credential protections (LSA protections where applicable, restrict credential store access, tighten admin boundaries).

## 8. SOC Relevance
Password cracking is often **indirectly observable**; SOC impact is highest when:
- You can detect the **hash acquisition** and **first abnormal successful logons**
- You can tie new authentications to privileged actions and lateral movement
- You maintain strong identity telemetry to spotlight “new device/new geo/new client” access

## 12. Mitigations
ATT&CK-listed mitigations for this subtechnique include:
- **M1032 - Multi-factor Authentication**: reduces value of recovered passwords for many access paths.
- **M1027 - Password Policies**: stronger policies reduce crack feasibility and password reuse risk.

## 13. Testing & Validation
- Validate visibility for credential-store access and suspicious bulk reads/copies.
- Validate identity detections for first-time successful logons after simulated credential exposure events.
- Ensure response steps cover: forced resets, token revocation, service account rotation, and privileged access review.
