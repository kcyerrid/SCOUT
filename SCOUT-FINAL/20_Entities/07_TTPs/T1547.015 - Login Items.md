# T1547.015 – Login Items

## 1. Technique Overview
**Login Items (T1547.015)** is a sub-technique of **Boot or Logon Autostart Execution (T1547)** in **MITRE ATT&CK v18**. Adversaries abuse macOS **Login Items** to automatically launch applications, scripts, or binaries when a user logs in. This mechanism is designed for user convenience and legitimate persistence, which allows malicious entries to blend into expected system behavior.

Depending on configuration and payload, this technique can provide reliable user-level persistence and may contribute to privilege escalation when combined with additional weaknesses.

## 2. Adversary Objectives
Adversaries use Login Items to:
- Maintain persistence across user logins
- Trigger execution through normal user behavior
- Avoid more scrutinized startup locations
- Blend malicious execution with legitimate macOS features

## 3. Common Abuse Patterns
- Adding malicious applications or scripts to Login Items via system APIs
- Registering background agents as Login Items to reduce visibility
- Masquerading entries as legitimate software or system utilities
- Leveraging Login Items to launch secondary payloads or scripts
- Using per-user Login Items to avoid administrative approval prompts

## 4. Detection Considerations
Detection relies on **macOS configuration and process monitoring**, including:
- Monitoring additions or changes to Login Items
- Auditing Login Items for unknown or unexpected entries
- Correlating login events with immediate execution of suspicious processes
- Reviewing use of APIs or commands that manage Login Items
- Comparing Login Items against approved software inventories

## 5. Defensive Mitigations
- Restrict the ability to add Login Items where feasible
- Regularly audit user Login Items across endpoints
- Use endpoint security tools with macOS persistence visibility
- Educate users to review and report unfamiliar Login Items
- Remove unauthorized Login Items during incident response

## 6. Operational Impact
If successful, T1547.015 can:
- Provide durable, low-noise user-level persistence
- Enable repeated execution without exploiting system services
- Evade detection if Login Items are not routinely reviewed
- Increase dwell time in macOS environments

## 7. Analyst Notes
Login Items persistence is straightforward but effective, especially in environments with limited macOS telemetry. Because entries are often created through legitimate APIs and user interfaces, defenders should emphasize **configuration auditing and behavioral correlation** rather than static signatures alone.
