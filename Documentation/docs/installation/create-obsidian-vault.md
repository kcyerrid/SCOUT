# Creating the base SCOUT Vault in Obsidian

1\. When you first launch Obsidian, you will be presented with the initial splash screen where you will choose to create a new vault.

![](https://colony-recorder.s3.amazonaws.com/files/2026-02-09/29e40f6c-2873-4055-bf1f-0bea9f0457ee/ascreenshot_7e9ac66aae21460d99bfaaafa0ea6135_text_export.jpeg)


2\. Name it what you want (I like SCOUT or SCOUT-DEMO)

![](https://colony-recorder.s3.amazonaws.com/files/2026-02-09/0e95ade4-7074-4372-904e-dd9f080ed861/ascreenshot_0a1bfe0cda9845e8beb81d161c0eea40_text_export.jpeg)


3\. Click Browse to determine where on disk the vault will go.

![](https://colony-recorder.s3.amazonaws.com/files/2026-02-09/a9bb4757-2059-40f4-9837-b421c19f1ea3/ascreenshot_f8a77d7511a54036ad8e6b5cb86da8c1_text_export.jpeg)


Alert: Alert!  There is a lot of literature out on the Internet about the best way to synchronize notes in Obsidian.  SCOUT has NOT been tested with Obsidian Sync, nor do I recommend storing the vault on a desktop synchronization application such as OneDrive.


4\. Click "Windows (C:)"

![](https://colony-recorder.s3.amazonaws.com/files/2026-02-09/55141298-2d1e-4cbf-b226-fb8b81840a4f/ascreenshot_4259694de138423b84e1131924e6636e_text_export.jpeg)


5\. Click "Select Folder"

![](https://colony-recorder.s3.amazonaws.com/files/2026-02-09/b50a5378-2040-47c0-af4e-3e9f4672f241/ascreenshot_a7bc9f96d7c14595809353a57b3149f4_text_export.jpeg)


6\. Click Create

![](https://colony-recorder.s3.amazonaws.com/files/2026-02-09/09463653-2e6d-48be-8502-41c9a940977f/ascreenshot_afd9b768a58b4752935aefe97e57a1c5_text_export.jpeg)


7\. Obsidian will load the new vault.

![](https://colony-recorder.s3.amazonaws.com/files/2026-02-09/919d34d4-6ddb-408a-b2eb-d40b855e2bdb/ascreenshot_e6dfa0c497424221ab0dffb19d57f0b4_text_export.jpeg)


8\. Once the Obsidian Vault has been created, it will come with a single default note called `Welcome`.  Right-click the note

![](https://colony-recorder.s3.amazonaws.com/files/2026-02-09/99a4e4b3-972c-4c29-85e8-54bfacbd3c61/ascreenshot_189f60d74e4441a9aa76ef8e7ec06fb9_text_export.jpeg)


9\. ...and select Delete to purge the sample note from your vault.

![](https://colony-recorder.s3.amazonaws.com/files/2026-02-09/6f9105a9-3ada-47a0-8a96-cd1ad0feb480/ascreenshot_6c30c48f7f9441f393f598ebd7cda4f8_text_export.jpeg)


10\. Optionally, select Don't ask again.

![](https://colony-recorder.s3.amazonaws.com/files/2026-02-09/7a80241d-c0d2-4b70-9cc2-d40e42bc8b56/ascreenshot_22fb8a3fc1634f23beba0c9e793388e4_text_export.jpeg)


11\. Click Delete

![](https://colony-recorder.s3.amazonaws.com/files/2026-02-09/c4da9117-8938-4741-a1dd-c00df7c64c77/ascreenshot_02ae8a23426248bc96f597124c0ebc8b_text_export.jpeg)
