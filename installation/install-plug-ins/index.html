    Installing the Obsidian Community Plug-ins

    1. Start by clicking on the Vault Settings (gear icon).

    2. Navigate to Community Plug-ins on the left-hand side of the Vault Settings dialog.

    3. Click the button to enable community plug-ins

    4. Click the Browse button in the Community plug-ins section.

    5. Begin typing the word templater

    6. Click the Templater plug-in

    7. Click Install

    8. Click Enable

    9. Search for Journals

    10. Click Journals

    11. Install the Journals plug-in

    12. Enable the Journals plug-in

    13. Search for Pixel Banner

    14. Select the Pixel Banner plug-in

    15. Install the Pixel Banner plug-in

    16. Enable the Pixel Banner plug-in

    17. Close the banner from the plug-in

    18. Search for File Explorer Note Count plug-in

    19. Select the File Explorer Note Count plug-in

    20. Install the File Explorer Note Count plug-in

    21. Enable the plug-in

    22. Search for charts

    23. Select the Charts plug-in

    24. Install the Charts plug-in

    25. Enable the Charts plug-in

    26. Search for Meta Bind

    27. Select the Meta Bind plug-in

    28. Install the Meta Bind plug-in

    29. Enable the Meta Bind plug-in

    30. Search for the IOC Lens plug-in

    31. Select the IOC Lens plug-in

    32. Install the IOC Lens plug-in

    33. Enable the IOC Lens plug-in

    34. Search for the Advanced Tables plug-in

    35. Select the Advanced Tables plug-in

    36. Install the Advanced Tables plug-in

    37. Enable the Advanced Tables plug-in

    38. Search for tasks plug-in

    39. Select the Tasks plug-in

    40. Install the Tasks plug-in

    41. Enable the Tasks plug-in

    42. Search for the Commander plug-in

    43. Select the Commander plug-in

    44. Install the Commander plug-in

    45. Enable the Commander plug-in

    46. Search for the Editing Toolbar plug-in

    47. Select the Editing Toolbar plug-in

    48. Install the Editing Toolbar plug-in

    49. Enable the Editing Toolbar plug-in

    50. Search for the chronos timeline plug-in

    51. Select the chronos timeline plug-in

    52. Install the Chronos Timeline plug-in

    53. Enable the Chronos Timeline plug-in

    54. Search for the Heatmap Tracker plug-in

    55. Select the Heatmap Tracker plug-in

    56. Install the Heatmap Tracker plug-in

    57. Enable the Heatmap Tracker plug-in

    Feel free to explore other plug-ins as well. These listed are simply the ones that are used for the SCOUT program.
